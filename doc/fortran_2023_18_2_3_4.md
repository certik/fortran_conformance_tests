### S18.2.3.4-001: C_F_PROCPOINTER argument restrictions

**Source:** S18.2.3.4; J3/24-007, 18 December 2023, physical PDF520. **Class:** Restriction.

**Definition:** CPTR is a scalar C_FUNPTR INTENT(IN) value denoting an interoperable C procedure address
or a C_FUNLOC result; FPTR is an INTENT(OUT) procedure pointer that is not a component
of a coindexed object and whose interface is interoperable with, or has the same
characteristics as, the target procedure.
