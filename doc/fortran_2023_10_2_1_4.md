### S10.2.1.4-001: A defined assignment statement is defined by a subroutine and ASSIGNMENT(=) generic interface

**Source:** 10.2.1.4 p1; J3/24-007 PDF p192. **Class:** Restriction.

**Definition:** A defined assignment statement is an assignment statement whose assignment is defined by
a subroutine and a generic interface specifying ASSIGNMENT(=). The detailed generic
interface and binding rules remain dependencies.

### S10.2.1.4-002: A subroutine defines x1 = x2 when dummy, generic, type, and parameter conditions match

**Source:** 10.2.1.4 p2 items (1)-(4); J3/24-007 PDF p193. **Class:** Restriction.

**Definition:** A subroutine defines the defined assignment x1 = x2 only if it is specified by a
SUBROUTINE or ENTRY statement with two dummy arguments d1 and d2, is provided through an
ASSIGNMENT(=) generic interface or matching type-bound generic binding, has d1 and d2
types compatible with the dynamic types of x1 and x2, and has matching corresponding
type parameters.

### S10.2.1.4-003: Defined-assignment rank matching has an elemental uniqueness alternative

**Source:** 10.2.1.4 p2 item (5); J3/24-007 PDF p193. **Class:** Restriction.

**Definition:** For a subroutine to define x1 = x2, either the ranks of x1 and x2 match those of d1 and
d2, or the subroutine is elemental, x2 is scalar or has the same rank as x1, and no
other subroutine defines the assignment.

**Diagnostic obligation:** context-dependent.

**Facets:** `rank-matched-specific-control`, `elemental-scalar-rhs-control`, `elemental-same-rank-rhs-control`, `elemental-ambiguous-other-subroutine-rejected`, `rank-mismatch-non_elemental-rejected`.

**Oracle:** The element-by-element interpretation of an eligible elemental defined assignment is
owned by 10.2.1.5; this rule only determines whether the subroutine defines the
assignment.

### S10.2.1.4-004: Array dummy shapes and elemental defined assignments impose shape/conformance conditions

**Source:** 10.2.1.4 p3; J3/24-007 PDF p193. **Class:** Restriction.

**Definition:** If d1 or d2 is an array, the shapes of x1 and x2 shall match the shapes of d1 and d2
respectively. If the defining subroutine is elemental, x2 shall be conformable with x1.
