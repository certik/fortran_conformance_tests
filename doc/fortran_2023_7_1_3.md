One base unit and nine fine units account for the value-domain definitions.
No executable is manufactured to prove an entire domain. Logical values,
processor-dependent integer/real/character domains, paired complex values,
derived component values, enum integer correspondence and enumerations'
listed ordinal values retain their different canonical premises.

In particular, enum types are not confined to their enumerators, enumeration
types are not integer kinds, and pointer/allocatable component values include
state rather than only payload. Native ASCII, IEEE representation and
undefined dynamic data are not used as implicit evidence. The parameter
catalogue retains the missing processor-value-set interface contract.
