### S9.5.3.4.3-001: A vector subscript sequence follows the values of the expression elements

**Source:** 9.5.3.4.3 p1 sentence 1, J3/24-007, 18 December 2023, physical PDF157. **Class:** Effect.

**Definition:** A vector subscript designates a sequence of subscripts corresponding to the values of
the elements of the vector-subscript expression. Type and rank of that expression are
owned by 9.5.3.1 C929; this rule owns the value-to-sequence correspondence and preserves
the expression element order, including repeated values in nondefining contexts.

**Diagnostic obligation:** not-required.

### S9.5.3.4.3-003: An array section with a vector subscript is not finalized by a nonelemental final subroutine

### S9.5.3.4.3-004: A vector-subscript section with duplicate subscript values is not definable and shall not be defined or become undefined

**Source:** 9.5.3.4.3 p3, J3/24-007, 18 December 2023, physical PDF157. **Class:** Restriction.

**Definition:** If a vector subscript has two or more elements with the same value, an array section
with that vector subscript is not definable and shall not be defined or become
undefined. A vector-subscript section without duplicate values is not rejected by this
rule merely for appearing in a variable-definition context, although all other
definability and context restrictions still apply.
