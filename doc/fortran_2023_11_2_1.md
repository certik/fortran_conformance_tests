### S11.2.1-001: Branching transfers control to a labeled branch target in the same inclusive scope

**Source:** 11.2.1 p1; J3/24-007 PDF p227. **Class:** Effect.

**Definition:** Branching is the Fortran control-transfer concept that alters the normal execution
sequence by transferring control from one statement to a labeled branch target statement
in the same inclusive scope. GO TO, computed GO TO, alternate-return CALL, and I/O END=,
EOR=, or ERR= specifiers can cause branches. Procedure references and control constructs
can transfer control but are not branches. The paragraph also enumerates the statement
kinds that can serve as branch targets.

**Diagnostic obligation:** not-required.
