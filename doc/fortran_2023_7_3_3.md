Compatibility is not dynamic-type equality, kind equality, equal LEN,
rank conformance, inheritance in both directions, or permission to ignore
allocation/association state. The enum exception requires an integer
expression with an enumerator primary from that very enum definition;
numerically equal integers and enumeration-type values are not substitutes.
CLASS(*) compatibility does not provide a declared type or relax TYPE(*)
use restrictions.
