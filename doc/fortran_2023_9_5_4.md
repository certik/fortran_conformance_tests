### S9.5.4-001: A section-subscript list specifies a simply contiguous section exactly under the no-vector colon-prefix conditions

**Source:** 9.5.4 p1, J3/24-007, 18 December 2023, physical PDF158. **Class:** Effect.

**Definition:** A section-subscript-list specifies a simply contiguous section if and only if it has no
vector subscript, all but the last subscript-triplet is a colon, the last
subscript-triplet has no stride, and no subscript-triplet is preceded by a
section-subscript that is a subscript.

### S9.5.4-002: An array designator is simply contiguous exactly for specified object-name, structure-component, or array-section forms

**Source:** 9.5.4 p2, J3/24-007, 18 December 2023, physical PDF158. **Class:** Effect.

**Definition:** An array designator is simply contiguous if and only if it is an object-name with
CONTIGUOUS, an object-name that is not a pointer, not assumed-shape, and not
assumed-rank, a structure-component whose final part-name is an array and either has
CONTIGUOUS or is not a pointer, or an array section satisfying all listed section
predicates: not a complex-part-designator, no substring-range, final part-ref nonzero
rank, rightmost part-name has CONTIGUOUS or is neither assumed-shape nor pointer, and no
section-subscript-list or a section-subscript-list that specifies a simply contiguous
section.

### S9.5.4-003: An array variable is simply contiguous exactly when its designator is simply contiguous or it is a contiguous pointer function reference
