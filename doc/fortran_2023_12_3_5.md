### S12.3.5-001: A file storage unit is the storage, position, record-length, and file-size unit

**Source:** S12.3.5, J3/24-007, 18 December 2023, physical PDF247-248. **Class:** Effect.

**Definition:** A file storage unit is the basic storage unit in a stream file or unformatted record
file, the unit of file position for stream access, the unit of record length for
unformatted files, and the unit of file size for all external files.

### S12.3.5-002: Values occupy integer file storage units with uniform unformatted scalar sizes
