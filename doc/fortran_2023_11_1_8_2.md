### S11.1.8.2-001: IF construct execution runs at most one block and exactly one block when ELSE is present

**Source:** 11.1.8.2 p1; J3/24-007 PDF p218-p219. **Class:** Effect.

**Definition:** At most one IF construct block is executed. If an ELSE statement appears, exactly one
block is executed. A true value or ELSE selects the immediately following block; with no
true evaluated expression and no ELSE, no construct block executes.

**Diagnostic obligation:** not-required.

**Facets:** `first-true-block-only`, `else-block-when-all-false`, `no-block-without-true-or-else`.

**Oracle:** Final sentinels observe which block executed.

### S11.1.8.2-002: IF construct logical expressions are evaluated in order until true, ELSE, or END IF, and later ELSE IF expressions are not evaluated

**Source:** 11.1.8.2 p1; J3/24-007 PDF p218-p219. **Class:** Effect.

**Definition:** The scalar logical expressions are evaluated in their construct order until a true value

### S11.1.8.2-003: Branching to END IF is permitted only within the IF construct and END IF has no effect

**Source:** 11.1.8.2 p2; J3/24-007 PDF p219. **Class:** Restriction.

**Definition:** It is permissible to branch to an END IF statement only from within its IF construct, so
an outside branch to that END IF is not permitted. Execution of an END IF statement has
no effect.

**Diagnostic obligation:** context-dependent.

**Facets:** `internal-end-if-branch-control`, `outside-end-if-branch-rejected`, `end-if-no-effect-control`.
