### R1033: An assignment statement has a variable, equals sign, and expression

**Source:** 10.2.1.1 R1033; J3/24-007 PDF p188. **Class:** Syntax.

**Definition:** The assignment-stmt syntax consists of a variable, the equals sign token, and an expr.
This rule only provides the general syntactic form; the statement must still be either
an intrinsic or a defined assignment statement.
