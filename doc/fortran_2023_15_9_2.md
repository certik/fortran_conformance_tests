### S15.9.2-001: Elemental function references have scalar or greatest-rank result shape and elementwise values

**Source:** 15.9.2 p1.result-shape; J3/24-007, 18 December 2023 PDF p362. **Class:** Effect.

**Definition:** An elemental function reference has result shape matching the actual argument of
greatest rank, or scalar result for no actual arguments or all scalar actual arguments;
in the array case, result elements have the values obtained by applying the scalar
function separately in array element order to corresponding array actual elements.
