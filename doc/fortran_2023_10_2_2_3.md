### S10.2.2.3-001: A data pointer assignment target is an ancestor component for a nonpolymorphic pointer to a polymorphic target with differing dynamic type

**Source:** 10.2.2.3 p1; J3/24-007 PDF p195. **Class:** Effect.

**Definition:** For data pointer assignment, a nonpolymorphic pointer object associated with a
polymorphic pointer target whose dynamic type differs from its declared type uses the
ancestor component of the pointer target that has the pointer object type as the
assignment target; otherwise the assignment target is the pointer target.

### S10.2.2.3-002: A data pointer object becomes associated, disassociated, or undefined according to the data pointer target status

**Source:** 10.2.2.3 p2; J3/24-007 PDF p195. **Class:** Effect.

is associated with an object, the pointer object becomes associated with the assignment
