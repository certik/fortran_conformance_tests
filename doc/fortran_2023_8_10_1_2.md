## Alignment is not universal value definition

Nonempty sequences share their first unit. Empty sequences associate
with each other and with the first unit of any nonempty sequences.
Through containing sequences or transitive sets, other objects can also
become associated. The plans distinguish nonempty, mixed-empty and
all-empty cases; a zero extent does not provide an element to reference.

Canonical19.5.3.2/.3 defines units, containing sequences and alignment.
These units are not assumed bytes or machine addresses.19.5.3.4 and
19.6 determine permitted partial overlap and definition state.
Cross-type, double-precision and default-COMPLEX relationships therefore
do not automatically permit observations of all overlapping objects.
The executable plans use small default INTEGER values and fully
qualified public sequence components. Further numeric-part value
mappings remain gated rather than inferred from representation.

A zero-array bridge is a concrete planned effect: two sets connect the
same whole empty sequence to two ordinary INTEGER scalars; a defining
store and independent observation follow the canonical unit-identity
rule. In contrast, an all-empty set needs a future source mechanism:
SIZE equality or a vacuous run would not demonstrate association.

COMMON is read only as a dependency. End extension, consistent complete
named-block sequences, no joining different blocks, no front extension
and default-initialization restrictions remain at8.10.2/8.10.3/19.5.3.
No COMMON catalogue or cross-scope fixture is authored here.
