### S10.1.7-001: A processor may omit evaluation of operands whose values are not needed

**Source:** 10.1.7 p1 and NOTE 1; J3/24-007 PDF p182-p183. **Class:** Effect.

**Definition:** If the value of an expression can be determined otherwise, the processor is not required
to evaluate all operands or to evaluate every part of an operand. This is evaluation
latitude, not a guarantee of short-circuiting or full evaluation.

**Diagnostic obligation:** not-required.

**Facets:** `operand-evaluation-omission-latitude`, `partial-operand-evaluation-omission-latitude`, `value-determined-otherwise-condition`, `all-expression-classes-caution`, `no-short-circuit-or-order-oracle`.

**Oracle:** This is a processor permission. Future valid programs and oracles must be invariant
whether the processor evaluates the optional operand, skips it, or evaluates only part
of it, subject to the rest of the standard.

**Oracle limitation:** This source-only catalogue records pending plans only. It creates no Fortran test
program, invokes no processor, approves no fixture or oracle, and claims no coverage.
Future cases must not infer which operand was evaluated, the order of evaluation, or
whether an optional evaluation was omitted; must not assert a result that a permitted
mathematically or logically equivalent rewrite could change; must not use floating-point
tolerance as an escape hatch; must not rely on compiler agreement, address arithmetic,
TRANSFER, emitted assembly, or undefined reads; and must attribute every negative to the
cited requirement rather than to an independently invalid rule owned elsewhere.

### S10.1.7-002: Entities that would be defined by an unneeded function reference become undefined when expression evaluation completes

**Source:** 10.1.7 p2 and NOTE 2; J3/24-007 PDF p183. **Class:** Effect.

**Definition:** When a statement contains a function reference in a part of an expression that need not
be evaluated, every entity that would have become defined during execution of that
reference becomes undefined at the completion of evaluation of the containing
expression.

**Diagnostic obligation:** not-required.

**Facets:** `unneeded-function-reference-context`, `would-be-defined-entities`, `undefined-at-expression-completion`, `independent-of-actual-invocation`, `no-undefined-read-oracle`.

### S10.1.7-003: An unneeded function reference shall not execute image control statements other than CRITICAL or END CRITICAL

**Source:** 10.1.7 p3 and NOTE 3; J3/24-007 PDF p183. **Class:** Restriction.

**Definition:** If a statement contains a function reference in a part of an expression that need not be
evaluated, no invocation of that function in that part of the expression is permitted to
execute an image control statement, except for CRITICAL or END CRITICAL.

**Diagnostic obligation:** not-required.

**Facets:** `image-control-ban-in-unneeded-function-reference`, `critical-statement-exception`, `end-critical-statement-exception`, `avoid-optimization-deadlock-pattern`, `collective-subroutine-not-this-image-control-statement-rule`.

**Oracle:** Future diagnostics or source reviews must isolate this optimization-safety restriction
and may not attempt to observe a deadlock, invocation order, or skipped invocation as
