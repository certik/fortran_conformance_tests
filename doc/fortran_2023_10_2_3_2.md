### S10.2.3.2-001: Executing a top-level WHERE statement or construct establishes control and pending masks

**Source:** 10.2.3.2 p1; J3/24-007 PDF p198. **Class:** Effect.

**Definition:** Executing a WHERE statement or where-construct-stmt establishes a control mask.
Executing a WHERE construct statement also establishes a pending control mask. For a
statement that is not part of a where-body-construct, the mask-expr is evaluated, the
control mask becomes that value, and a top-level WHERE construct establishes the pending
control mask as the logical negation of that mask value.

**Diagnostic obligation:** not-required.

**Facets:** `top-level-where-stmt-selected-elements`, `top-level-where-construct-initial-then-region`, `top-level-where-construct-initial-pending-region`.

**Oracle:** Use side-effect-free masks with preloaded sentinel values. This rule establishes
top-level control masks; nested conjunction is p7/p8 and per-element assignment effects
remain 10.2.1.3 dependencies.

**Oracle limitation:** This source-only catalogue records pending plans only. It creates no Fortran test
program, invokes no processor, approves no fixture or oracle, and claims no coverage.

### S10.2.3.2-002: WHERE and masked ELSEWHERE mask expressions are evaluated at most once per statement execution

### S10.2.3.2-003: Statements in a WHERE construct execute in construct order

**Source:** 10.2.3.2 p3; J3/24-007 PDF p198. **Class:** Effect.

### S10.2.3.2-007: A nested WHERE construct conjoins the outer control mask with its mask and complement

### S10.2.3.2-009: Non-elemental function references in masked assignments evaluate without masked control, with array results selected by the control mask

**Source:** 10.2.3.2 p9; J3/24-007 PDF p199. **Class:** Effect.

**Definition:** If a non-elemental function reference occurs in the expr or variable of a
where-assignment-stmt or in a mask-expr, the function is evaluated without masked
control: all of its argument expressions are fully evaluated and the function is fully
evaluated. If the result is an array and the reference is not within the argument list
