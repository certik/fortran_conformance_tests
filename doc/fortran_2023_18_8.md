### S18.8-001: C descriptors and C pointers to Fortran objects become undefined with matching Fortran pointer conditions

**Source:** S18.8 p1; J3/24-007, 18 December 2023, physical PDF543. **Class:** Undefined result.

**Definition:** A C descriptor of, or C pointer to, any part of a Fortran object becomes undefined under
the same conditions as a Fortran pointer associated with that object, and further use
has C undefined behavior.

**Diagnostic obligation:** not-required.

**Facets:** `c-descriptor-undefined-with-fortran-pointer-status`, `c-pointer-undefined-with-fortran-pointer-status`, `further-use-of-undefined-c-view-is-undefined-behavior`.

CFI calls, and required diagnostics for numbered constraints. Program obligations on C
descriptors, object lifetimes, setjmp/longjmp, signal handling, floating-point status,
and asynchronous communication are not treated as required diagnostics unless a numbered
