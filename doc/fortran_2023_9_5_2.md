### S9.5.2-001: A whole array is a named array or final array component with no appended subscript list

**Source:** 9.5.2 p1, J3/24-007, 18 December 2023, physical PDF154. **Class:** Effect.

**Definition:** A whole array is either a named array or a structure component whose final part-ref is
an array component name, and no subscript list is appended. This distinguishes a whole
array from an array element or array section, whose final or relevant part-ref carries
subscripts or section subscripts under 9.5.3.1 and 9.4.2.

### S9.5.2-002: Whole array appearances designate all elements in executable constructs and the entire array in nonexecutable statements except equivalence sets

**Source:** 9.5.2 p2 sentences 1-2, J3/24-007, 18 December 2023, physical PDF154. **Class:** Effect.

entire array, except that an appearance in an equivalence set has the special effect

### S9.5.2-003: Assumed-size arrays may appear as whole arrays only as actual arguments when shape is not required

**Source:** 9.5.2 p2 sentence 3, J3/24-007, 18 December 2023, physical PDF154. **Class:** Restriction.

**Definition:** An assumed-size array is permitted to appear as a whole array in an executable construct
