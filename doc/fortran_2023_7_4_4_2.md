### R721: Character selectors preserve each length and kind keyword ordering

**Source:** 7.4.4.2 R721; J3/24-007, 18 December 2023, PDF 84, printed 70, lines 25-31. **Class:** Syntax.

**Definition:** A char-selector can be a length-selector; (LEN=L,KIND=K); (L,K); (L,KIND=K); (KIND=K);
or (KIND=K,LEN=L). Here L is a type-param-value subject to its enclosing context, and K
is a scalar integer constant expression satisfying C724. The length-first keyword form
requires KIND=, while the kind-first form requires LEN= if a length is supplied. A
single positional expression specifies length, not kind. The expression specifying KIND
need not itself have default integer kind, but any conversion used to produce its value
must be representable.

**Diagnostic obligation:** required.

**Facets:** `length-selector-alternative`, `len-kind-keywords`, `positional-len-kind`, `positional-len-keyword-kind`, `kind-only`, `kind-len-keywords`, `len-keyword-positional-kind-exclusion`, `kind-keyword-positional-length-exclusion`, `integer-expression-kind`, `kind-expression-premises`.

**Oracle:** Five run controls cover the kind-bearing selector orderings, with exact LEN, KIND and
value assertions. Two one-substitution compile pairs isolate the LEN-first and
KIND-first keyword exclusions. Their predicates require the specific offending token or
ordering cause, not generic expected-parenthesis recovery. Canonical expression-category
and optional bounded identifier-conversion work remains pending. Direct case IDs:
R721_invalid__kind_keyword_positional_length, R721_invalid__len_keyword_positional_kind,
R721_valid__kind_keyword_positional_length_repair, R721_valid__kind_len_keywords,
R721_valid__kind_only, R721_valid__len_keyword_positional_kind_repair,
R721_valid__len_kind_keywords, R721_valid__positional, R721_valid__positional_keyword.

**Oracle limitation:** Direct cases are authored but not independently approved. Scalar LEN does not imply
constant LEN in all scopes; scalar constant KIND is different from LEN's
context-specific specification expression. Reporting follows numbered syntax/constraints
and 4.2 p2(3), not compulsory fatal rejection. Use exact source relations and
case-specific causal predicates; crashes, ASR verifier errors, unsupported language
features and wrong-source recovery cannot pass.

**Dependencies:** R701/C701/C702 (PDF 76), C704/R703 (PDF 77), R704 and 7.4.3.1 p2/p4 (PDF 80),

### R722: Length selectors have parenthesized and star forms

**Source:** 7.4.4.2 R722; PDF 84, printed 70, lines 32-33. **Class:** Syntax.

**Definition:** A length-selector is a parenthesized type-param-value with optional LEN=, or a star
followed by char-length and an optional comma. The latter comma is only permitted under
C729 and C730. R701 supplies the scalar integer expression, assumed asterisk and
deferred colon alternatives; C704, C702, C726, C731 and other enclosing rules determine
which uses are legal. Neither OPTIONAL nor ALLOCATABLE/POINTER alone bans an
assumed-length character dummy.

**Diagnostic obligation:** required.

**Facets:** `parenthesized-lengths`, `star-forms`, `optional-comma`, `integer-expression-kind`, `length-expression-premises`.

**Oracle:** Run controls exercise both parenthesized forms, both legacy star forms, the optional
legacy comma without ::, and small integer-kind-selected length expressions. The
SELECTED_INT_KIND(4) witness uses only value 3; default integer range at least five
guarantees a qualifying method, not a distinct or wider kind. Direct case IDs:
R722_valid__comma, R722_valid__parentheses, R722_valid__selected_length_expression,
R722_valid__star_forms.

**Oracle limitation:** The optional comma is not generally allowed in ALLOCATE, components, TYPE wrappers or
function prefixes. The older CHARACTER* form is obsolescent, not deleted. The four
deferred establishment mechanisms are already planned/covered under the 7.2 owner; this
syntax wrapper does not relabel those effects.

### C724: A character selector kind is nonnegative and supported

**Source:** 7.4.4.2 C724 (R721); PDF 84, printed 70, lines 36-37. **Class:** Restriction.

**Definition:** The scalar integer constant expression selecting character kind has a nonnegative value
and identifies a character representation method supported by the processor. This is
independent of whether the expression is scalar, integer and constant. Zero is not
universally an invalid kind, and a kind supported for another intrinsic type need not be
a supported character kind.

**Diagnostic obligation:** required.

**Facets:** `supported-kind`, `negative-kind`, `unsupported-nonnegative-kind`.

**Oracle:** Unprofiled compile controls use a supported KIND inquiry. A negative/control pair
changes only -1 to KIND('A'). Unsupported representation-value reports are intended;
false constancy and unsupported-language-feature reports are excluded. Nonnegative
absent-kind witnesses remain pending independent qualification. Direct case IDs:
C724_invalid__negative, C724_valid__negative_repair, C724_valid__supported.

**Oracle limitation:** Numbered reporting capability and 4.2 p2(4) do not require fatal rejection in every mode
or particular words. Case-specific source/value predicates must exclude generic
kind/parameter strings, wrong constancy causes, crashes, verifier failures, resource
errors and wrong-source recovery. No full supported-kind inventory is proved by these
three cases.

**Dependencies:** R721; 7.4.4.1 p2 and 7.4.4.2 p2-p3 (PDF 84); 16.9.118 (PDF 424); 16.10.2.4 (PDF 472);

**Definition:** Character length can come from the CHARACTER selector or an individual *char-length in
an entity or component declaration. The individual value overrides the selector's length
for that entity/component only. Without an individual length, the selector's length
applies; if neither specifies a length, it is one. The override does not change kind,
other entities' lengths or array rank.

**Diagnostic obligation:** not-required.

**Facets:** `selector-inheritance`, `entity-override`, `component-override`, `omitted-length-one`.

**Oracle:** Four run programs separately check selector inheritance, individual entity overrides,
individual component overrides and omitted length one. Overrides 2/0 leave siblings at
length 5 and do not change kind. Initialized payloads and exact lengths are checked
independently. Direct case IDs: S7_4_4_2_004_valid__component,
S7_4_4_2_004_valid__default_one, S7_4_4_2_004_valid__entity,
S7_4_4_2_004_valid__selector.

**Oracle limitation:** No default-integer LEN kind, storage size or inferred default character kind number is

### S7.4.4.2-005: A negative character length specification denotes zero length

**Source:** 7.4.4.2 p5, first sentence; PDF 85, printed 71, lines 17-18. **Class:** Effect.

**Definition:** When a character length parameter specification evaluates to a negative value, the
declared character entity has length zero. The specification's value may be negative
while the resulting LEN parameter is nonnegative. Zero and negative expressions are not
invalid twins, and a bare signed token must not be confused with a legal parenthesized
negative expression.

**Diagnostic obligation:** not-required.

**Facets:** `constant-negative`, `runtime-negative`, `individual-negative`.

**Oracle:** Three valid run cases exercise constant, nonoptional-dummy-dependent and
individual/component negative length specifications using small values -2, 0 and 3. They
require resulting length zero rather than a diagnostic or trap; no empty position is
accessed. Direct case IDs: S7_4_4_2_005_valid__constant, S7_4_4_2_005_valid__individual,
S7_4_4_2_005_valid__runtime.

**Oracle limitation:** No required diagnostic, exception, runtime trap or negative fixture is inferred from
this interpretation. This plan does not extend declaration wording into every
allocation/substring context without its canonical premises.

### S7.4.4.2-006: Each assumed-length context has its own source of length

**Source:** 7.4.4.2 p5, asterisk introduction and all five bullets; PDF 85, printed 71, lines 18-29. **Class:** Effect.

**Definition:** An assumed-length character dummy takes its length from its effective argument; an
assumed-length named constant takes it from its constant value. In the permitted
ALLOCATE type-spec context, each object takes the length from its own effective
argument. In a type guard, the associating entity takes it from the selector.

For an external assumed-length function result, every scope that invokes the function or
passes it as an actual argument must declare a nonasterisk character length for the
function name, or access such a definition by argument, host or use association. On
invocation that parameter value supplies the result's length. The asterisk is not a
return-time inference from the assigned text. The declaration whitelist, procedure
characteristics, argument association and each function restriction still apply.
