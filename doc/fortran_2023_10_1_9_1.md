### S10.1.9.1-001: Expression characteristics are determined recursively from syntax, operators, and primaries

**Source:** 10.1.9.1 p1; J3/24-007 PDF p183. **Class:** Effect.

**Definition:** The type, type parameters, and shape of an expression depend on the operators and on the
types, type parameters, and shapes of the primaries used in the expression. Those
characteristics are determined recursively from the expression's syntactic form, and the
expression type is either an intrinsic type or a nonintrinsic type.

**Diagnostic obligation:** not-required.

**Facets:** `operator-and-primary-characteristics`, `recursive-syntactic-characteristics`, `intrinsic-expression-type-domain`, `nonintrinsic-expression-type-domain`.

**Oracle:** Observe expression characteristics through valid typed contexts, assignment to declared
destinations, and standard inquiries whose expected values are required by cited source
rules rather than assumed from a processor's usual kind set.

### S10.1.9.1-002: Polymorphic primaries and defined operations propagate declared and dynamic expression properties

**Source:** 10.1.9.1 p2; J3/24-007 PDF p183. **Class:** Effect.

**Definition:** If an expression is a polymorphic primary or a defined operation, the expression has the
same type parameters and declared and dynamic types as that primary or defined
operation. Otherwise its type parameters and dynamic type are the same as its declared
type and type parameters; in those non-exception cases the standard refers to them
simply as the expression's type and type parameters.

**Diagnostic obligation:** not-required.

**Facets:** `polymorphic-primary-declared-and-dynamic-types`, `defined-operation-declared-and-dynamic-types`, `nonpolymorphic-dynamic-type-equals-declared-type`, `simple-type-parameter-terminology`.

**Oracle:** Use dynamic-type observations only where the source requires a dynamic/declared
distinction. Do not infer dynamic type from storage representation or compiler
diagnostics; use standard type-selection or inquiry mechanisms with independently
required expectations.

program, invokes no processor, approves no fixture or oracle, and claims no coverage.
