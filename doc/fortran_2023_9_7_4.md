### R946: A STAT variable is a scalar integer variable

**Source:** 9.7.4 R946, J3/24-007, 18 December 2023, physical PDF166. **Class:** Syntax.

**Definition:** The grammar for stat-variable is scalar-int-variable. A STAT= specifier in an ALLOCATE
or DEALLOCATE statement therefore designates a scalar integer variable; scalarity,
integer type, and variable status are all required by this rule. Image-selector-specific
exclusions for STAT targets are owned by 9.6, not by this ALLOCATE/DEALLOCATE subclause.

### S9.7.4-001: A STAT variable is independent of allocation actions, allocate-object properties, and ERRMSG value

**Source:** 9.7.4 p3, J3/24-007, 18 December 2023, physical PDF167. **Class:** Restriction.

**Definition:** The stat-variable shall not itself be allocated or deallocated within the ALLOCATE or
DEALLOCATE statement in which it appears. Its denotation shall not depend on the value,
bounds, deferred type parameters, allocation status, or association status of any

errmsg-variable. These are real restrictions on the statement semantics, but because

### S9.7.4-003: STAT values distinguish stopped images, failed images without other errors, and other errors

**Source:** 9.7.4 p5, J3/24-007, 18 December 2023, physical PDF167. **Class:** Effect.

**Definition:** For an ALLOCATE statement with a coarray allocate-object, or a DEALLOCATE statement with
an allocate-object that is a coarray or has a coarray potential subobject component,
execution when the current team contains a stopped image defines stat-variable with
STAT_STOPPED_IMAGE from ISO_FORTRAN_ENV. Otherwise, if such a statement is executed when
the current team contains a failed image and no other error condition occurs,
stat-variable is defined with STAT_FAILED_IMAGE from ISO_FORTRAN_ENV. If any other error
condition occurs during ALLOCATE or DEALLOCATE execution, stat-variable is defined with
a processor-dependent positive integer value different from STAT_STOPPED_IMAGE and
STAT_FAILED_IMAGE.

### S9.7.4-004: Object status after STAT_FAILED_IMAGE and other STAT errors follows the specified success or retention rules

**Source:** 9.7.4 p6, J3/24-007, 18 December 2023, physical PDF167. **Class:** Effect.

**Definition:** If stat-variable became defined with STAT_FAILED_IMAGE, each allocate-object is
successfully allocated or deallocated on all active images of the current team. If any
other error condition occurs, each allocate-object has a processor-dependent status,
subject to three guarantees: an object successfully allocated has allocation status
allocated or pointer association status associated; an object successfully deallocated
has allocation status unallocated or pointer association status disassociated; and an
object not successfully allocated or deallocated retains its previous allocation status
or pointer association status.
