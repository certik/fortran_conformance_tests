## OPEN specifier fixture derivations

### `round_value_up_token` / `S12.5.6.17-001`

**Facets:** `round-value-set`.

12.5.6.17 p1 lists UP as a ROUND value; INQUIRE(ROUND=) returns the fixed token for that formatted connection.

Feature mutations: `round-up-to-down-token`.

### `round_mode_effect` / `S12.5.6.17-003`

**Facets:** `round-mode-effect`.

12.5.6.17 p1 specifies the I/O rounding mode; exact 1.125 is not a tie for F4.1, so UP gives 1.2 and DOWN gives 1.1.

Feature mutations: `round-up-to-down-output`, `round-down-to-up-output`.

### `round_changeable_mode` / `S12.5.6.17-004`

**Facets:** `round-changeable-mode`.

12.5.6.17 p1 says ROUND is changeable; after same-unit OPEN changes DOWN to UP, INQUIRE and F output observe UP.

Feature mutations: `round-changeable-keeps-down`.

### `round_default_listed_mode` / `S12.5.6.17-006`

**Facets:** `round-default-one-of-listed-modes`.

12.5.6.17 p1 makes the omitted ROUND mode processor dependent but one of the six listed modes; INQUIRE returns a member token only.

Feature mutations: `round-default-inquire-after-close`.
