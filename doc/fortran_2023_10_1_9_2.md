### S10.1.9.2-001: A nonparenthesized primary gets its characteristics from its primary alternative

**Source:** 10.1.9.2 p1; J3/24-007 PDF p184. **Class:** Effect.

**Definition:** The type, type parameters, and shape of a primary are determined by which primary
alternative appears. Literal constants, constructors, array constructors, designators,
function references, generic function references, type parameter inquiries, and type
parameter names take the characteristics specified for those alternatives in their
owning subclauses; type parameter inquiries and type parameter names are scalar integers
with the kind of the type parameter.

**Diagnostic obligation:** not-required.

**Facets:** `literal-constant-primary-characteristics`, `structure-constructor-scalar-characteristics`, `enum-constructor-scalar-type`, `enumeration-constructor-scalar-type`, `array-constructor-characteristics`, `designator-primary-characteristics`, `function-reference-primary-characteristics`, `generic-function-specific-characteristics`, `type-parameter-inquiry-or-name-scalar-integer-kind`.

**Oracle:** Use each primary alternative in a context where its characteristics are observable,
while citing the owning subclause for the alternative's internal semantics. Do not
replace missing alternative coverage with compiler agreement.

### S10.1.9.2-002: A parenthesized-expression primary has the expression's characteristics

**Source:** 10.1.9.2 p2; J3/24-007 PDF p184. **Class:** Effect.

### S10.1.9.2-003: A pointer primary in listed expression contexts references its associated target

**Source:** 10.1.9.2 p3 sentences 1-2; J3/24-007 PDF p184. **Class:** Effect.

**Definition:** When a pointer appears as a primary in an intrinsic or defined operation, as the expr of
a parenthesized primary, or as the only primary on the right-hand side of an intrinsic
assignment statement, the associated target object is referenced. The primary's type,
type parameters, and shape are those of that target.

**Diagnostic obligation:** not-required.

**Facets:** `pointer-primary-in-intrinsic-operation`, `pointer-primary-in-defined-operation`, `pointer-primary-in-parenthesized-primary`, `pointer-primary-only-rhs-intrinsic-assignment`, `pointer-primary-target-characteristics`.

**Oracle:** Use associated pointers whose targets have independently declared and literal-observable
characteristics. Avoid address comparisons and avoid unassociated pointer references

### S10.1.9.2-004: A disassociated pointer primary is restricted to pointer-accepting or explicitly permitted contexts

**Source:** 10.1.9.2 p3 sentence 3; J3/24-007 PDF p184. **Class:** Restriction.

**Definition:** If a pointer is not associated with a target, it shall appear as a primary only as an
actual argument corresponding to a pointer dummy argument, as the target in a pointer

### S10.1.9.2-005: Disassociated or unallocated array entities lack shape but retain rank, and NULL result characteristics depend on context

**Source:** 10.1.9.2 p4; J3/24-007 PDF p184. **Class:** Effect.

**Definition:** A disassociated array pointer and an unallocated allocatable array have no shape but do
have rank. The type, type parameters, and rank of the result of the intrinsic function
NULL depend on context.

**Diagnostic obligation:** not-required.

**Facets:** `disassociated-array-pointer-has-rank-no-shape`, `unallocated-allocatable-array-has-rank-no-shape`, `null-result-contextual-type-parameters-rank`.

**Oracle:** No future oracle may fabricate a shape for a disassociated array pointer or unallocated
allocatable array. Rank and NULL context are observable only through contexts that the
standard separately permits.
