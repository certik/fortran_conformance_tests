### S10.1.2.3-001: A conditional expression is a primary selecting a chosen subexpression

**Source:** 10.1.2.3 p1; J3/24-007 PDF p169. **Class:** Effect.

**Definition:** A conditional expression is classified as a primary and selects a chosen subexpression.
The detailed conditional evaluation rules, including which guards or expressions are
evaluated, are dependencies rather than local fixture coverage.

**Diagnostic obligation:** not-required.

**Facets:** `primary-classification`, `true-arm-selection`, `false-arm-selection`, `nested-selection`.

**Oracle:** Future controls use distinct literal arm values and separately satisfy C1004. They must
not claim short-circuit evaluation coverage beyond the rules later catalogued for
10.1.4.

### R1002: A conditional expression has parenthesized guarded arms and a final fallback expression

**Source:** 10.1.2.3 R1002; J3/24-007 PDF p169. **Class:** Syntax.

**Definition:** The conditional-expr syntax is an opening parenthesis, a scalar-logical-expr guard,
question mark, an expr, zero or more ': scalar-logical-expr ? expr' repetitions, a
colon, a final expr, and a closing parenthesis.

**Diagnostic obligation:** required.

**Facets:** `two-arm-form`, `chained-guard-form`, `scalar-logical-guard`, `missing-final-colon-rejected`, `missing-question-rejected`.

**Oracle:** Syntax negatives must keep all expressions declared and C1004-compatible so the
malformed conditional punctuation or shape is the only cited defect.

### C1004: All conditional-expression result arms have the same declared type, kind parameters, and rank

**Source:** 10.1.2.3 C1004; J3/24-007 PDF p169. **Class:** Restriction.

**Definition:** Each expr result arm of a conditional-expr shall have the same declared type, the same
kind type parameters, and the same rank. The constraint applies to all selectable result
expressions, not to the scalar logical guards.

**Diagnostic obligation:** required.

**Facets:** `same-characteristics-control`, `declared-type-mismatch-rejected`, `kind-parameter-mismatch-rejected`, `rank-mismatch-rejected`, `nested-arm-characteristics`.

**Oracle:** Negative plans must use syntactically valid conditionals with scalar logical guards so
the reported defect is the arm characteristic mismatch, not malformed R1002 syntax or
invalid logical expressions.
