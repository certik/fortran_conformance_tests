## WAIT/position/FLUSH fixture derivations

### `backspace_forms` / `R1224`

**Facets:** `backspace-unit-number-form`, `backspace-position-spec-list-form`.

R1224 gives both BACKSPACE unit-number and parenthesized position-spec-list forms; each form repositions a known sequential file and exact read-back observes the form used.

Feature mutations: `remove-backspace-unit-form`, `remove-backspace-position-form`, `r1224-second-record-changed`.

### `endfile_forms` / `R1225`

**Facets:** `endfile-unit-number-form`, `endfile-position-spec-list-form`.

R1225 gives both ENDFILE unit-number and position-spec-list forms; each writes an endfile marker after a known record, observed by exact read-back and IOSTAT_END.

Feature mutations: `replace-endfile-unit-form-with-data`, `replace-endfile-position-form-with-data`, `r1225-position-record-changed`.

### `rewind_forms` / `R1226`

**Facets:** `rewind-unit-number-form`, `rewind-position-spec-list-form`.

R1226 gives both REWIND unit-number and position-spec-list forms; after the unit-number form and later position-spec-list form, the next exact read is the first record.

Feature mutations: `remove-rewind-unit-form`, `remove-rewind-position-form`, `r1226-first-record-changed`.

### `position_specifiers` / `R1227`

**Facets:** `position-unit-specifier-form`, `position-iostat-specifier-form`, `position-iomsg-specifier-form`, `position-err-label-specifier-form`.

R1227 admits UNIT, IOSTAT, IOMSG, and ERR position specifiers; separate BACKSPACE/REWIND observations exercise UNIT targeting, IOSTAT zero, IOMSG syntax without text comparison, and no ERR branch.

Feature mutations: `position-unit-specifier-target-other`, `position-remove-iostat-specifier`, `position-iomsg-as-iostat-probe`, `position-err-label-target`.

### `position_duplicate_iostat` / `C1241`

**Facets:** `position-duplicate-specifier-rejected`.

C1241 prohibits duplicate position specifiers; the conforming control removes only the second IOSTAT= specifier.

Conforming control: `position_specifiers`.
