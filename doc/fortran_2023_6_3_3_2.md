### S6.3.3.2-001: Fixed-form commentary is recognized by context and column and has no program effect

**Source:** 6.3.3.2 p1; J3/24-007, 18 December 2023, PDF page 73, printed page 59, lines 2-6. **Class:** Effect.

**Definition:** Outside a character context and position 6, an exclamation mark begins commentary
through the end of its line. A first nonblank exclamation mark outside position 6 makes
a comment line, including in the label field. C or an asterisk in position 1 also makes
a comment line; an all-blank line is a comment line. Such comments may occur within,
before, or after a program unit without affecting its interpretation. An exclamation
mark in a literal or character string edit descriptor is data, and one in position 6
outside commentary is a continuation indicator, not commentary.

**Diagnostic obligation:** not-required.

**Facets:** `inline-comment`, `bang-columns-one-to-five`, `bang-column-seven`, `bang-column-72`, `c-column-one`, `asterisk-column-one`, `all-blank-line`, `before-unit`, `within-unit`, `after-unit`, `comment-through-end`, `literal-exception`, `edit-descriptor-exception`, `column-six-exception`, `noncomment-c-and-asterisk`.

**Oracle:** The markers control uses every label-field exclamation position, positions 7 and 72, C/c
and asterisk in position 1, all-blank 72-character lines, and comments before and after
the unit. Invalid-looking assignment/error-stop text in those comments must not execute
or be parsed. The inline control checks that trailing statement-looking text through
column 72 has no effect. A character-context control checks literal and internal FORMAT
output containing an exclamation mark. A fourth control checks numeric continuation
through an exclamation in column 6; ordinary count and multiplication text in the
statement field remain executable.

**Oracle limitation:** The informative note gives no numerical cap on consecutive comments; a finite run is
only a witness, not an unbounded resource test. Every new record is exactly 72
characters; the free-form permission for zero-character comment lines is not imported.
Only supported default-kind graphic characters are used. No tab expansion, arbitrary
control or Unicode repertoire, mandatory currency graphic, directive extension, or
collating code is assumed.

**Dependencies:** 3.21 (both character contexts), 6.1.2 (C/c equivalence outside character context), 6.3.1
p2 (comment repertoire), 6.3.3.1 (line width), 6.3.3.3 (position 6 and intervening
comments), and 6.3.3.4 (termination). R724 and 13.2.1/13.3.2 retain the
literal/edit-descriptor grammar. No comment-continuation rejection obligation is
manufactured here.
