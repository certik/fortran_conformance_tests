### S11.1.3.3-001: Associating entities have selector rank and bounds with no ALLOCATABLE or POINTER attributes

**Source:** 11.1.3.3 p1; J3/24-007 PDF p204-p205. **Class:** Effect.

**Definition:** Within ASSOCIATE, CHANGE TEAM, or SELECT TYPE, each associating entity has the same rank
as its selector. Each lower bound is the LBOUND result for the corresponding selector
dimension, and each upper bound is lower bound plus extent minus one. The associating
entity does not have ALLOCATABLE or POINTER.

**Diagnostic obligation:** not-required.

**Facets:** `same-rank-as-selector`, `nondefault-lower-bound`, `upper-bound-from-extent`, `no-allocatable-attribute-source`, `no-pointer-attribute-source`.

**Oracle:** LBOUND/UBOUND/SHAPE inquiries are acceptable only because this paragraph requires the
expected bounds; future plans must avoid circular use of array-section formation as the
sole oracle.

**Oracle limitation:** This source-only catalogue records pending plans only. It creates no Fortran test
program, invokes no processor, approves no fixture or oracle, and claims no coverage.
Future ASSOCIATE fixtures must use non-vacuous selectors and sentinels: lower bounds
must differ where bounds are asserted, character length must be checked with LEN rather
than inferred from padded comparison, outer homonyms must start with values different

### S11.1.3.3-002: Associating entities have selector corank and selector cobounds for coarray selectors

### S11.1.3.3-004: Associating entities inherit ASYNCHRONOUS, VOLATILE, dynamic type, optional absence, and contiguity properties as specified

**Source:** 11.1.3.3 p4; J3/24-007 PDF p205. **Class:** Effect.

**Definition:** Within ASSOCIATE, CHANGE TEAM, SELECT RANK, or SELECT TYPE, the associating entity has
ASYNCHRONOUS or VOLATILE if and only if the selector is a variable and has the
attribute. If polymorphic, it assumes the selector dynamic type and type parameter
values. It does not have OPTIONAL; an OPTIONAL selector cannot be absent. It is
contiguous if and only if the selector is contiguous.

### S11.1.3.3-005: Associating entities are variables but are not definable when their selectors are not definable or not permitted in definition contexts

**Source:** 11.1.3.3 p5; J3/24-007 PDF p205. **Class:** Restriction.

**Definition:** The associating entity itself is a variable. If the selector is not a definable
variable, the associating entity is not definable and shall not be defined or become
undefined. If a selector is not permitted in a variable definition context, neither the
associate name nor any subobject of it shall appear in a variable definition context or
pointer association context.
