### R516: Keywords use name syntax

**Source:** 5.5.3 R516, J3/24-007, 18 December 2023, physical PDF65. **Class:** Syntax.

**Definition:** The syntax nonterminal keyword is a name. The rule supplies the name-shaped keyword
token used by argument lists, type parameter specifications, component specifications
and other enclosing lists; it does not own placement, duplication, optionality or the
existence of a matching item.

**Diagnostic obligation:** required.

**Facets:** `actual-argument-keyword-name`, `type-parameter-keyword-name`, `component-keyword-name`, `name-syntax-delegation`.

**Oracle:** Positive controls use exact integer and character-length observations in contexts that
already require the enclosing list form to be otherwise conforming.

**Oracle limitation:** Every malformed keyword spelling also violates name syntax under R603, and many keyword
mistakes violate enclosing list rules. No diagnostic facet is attributed solely to R516
without a future source-use review that isolates the grammar link.
