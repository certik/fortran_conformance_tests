### S10.1.5.3.1-001: The character intrinsic operator concatenates same-kind character operands and produces character result type

**Source:** 10.1.5.3.1 p1; J3/24-007 PDF p178. **Class:** Restriction.

**Definition:** The character intrinsic operator // concatenates two operands of type character with the
same kind type parameter, and evaluating the character intrinsic operation produces a
result of type character.

**Diagnostic obligation:** context-dependent.

**Facets:** `default-character-same-kind`, `nondefault-same-kind-profile`, `different-kind-boundary`, `character-result-type`.

**Oracle:** Character value oracles must compare equal-length character values or assert LEN
explicitly before comparison; shorter-operand blank padding in relational comparisons
cannot be used to hide a wrong concatenation length.

### S10.1.5.3.1-002: Character concatenation forms the right-appended value with length equal to the sum of operand lengths

**Source:** 10.1.5.3.1 p2-p3 and Table 10.4; J3/24-007 PDF p178. **Class:** Effect.

**Definition:** Table 10.4 interprets x1 // x2 as concatenating x1 with x2. The result value is the
value of x1 concatenated on the right with the value of x2, and the result length is the
sum of the operand lengths. The table has a single row and its column extraction is
unambiguous after row-by-row checking.

**Diagnostic obligation:** not-required.

**Facets:** `right-append-value`, `result-length-sum`, `zero-length-left`, `zero-length-right`.

**Oracle:** Always assert LEN for concatenation results and use expected character values of the
same length as the result. Do not credit comparisons where relational blank padding
could make an incorrect length appear equal.

### S10.1.5.3.1-003: Parentheses specifying evaluation order do not affect the value of a character expression

**Source:** 10.1.5.3.1 p3 final sentence; J3/24-007 PDF p178. **Class:** Effect.

**Definition:** For character expressions using the character intrinsic operation, parentheses used to
specify the order of evaluation have no effect on the character expression's value.

**Diagnostic obligation:** not-required.

**Facets:** `left-grouped-concatenation-value`, `right-grouped-concatenation-value`, `nested-parentheses-value`.

**Oracle:** Observe only the final character value and length. Parentheses here do not license any
inference about whether a particular operand expression was evaluated before another.
