## Literal syntax and complete admissible contexts

The original R838 uses `coarray-name lbracket coarray-spec rbracket`.
R779/R780 define `[` and `]`: these are **mandatory literal delimiters**,
not BNF marks making the specification optional. Every item has its own
group. Only R837's double colon is optional. A standalone listless
CODIMENSION statement is not a listless all-objects attribute declaration.

The production has no ordinary parenthesized array-spec slot. A complete
module can separately declare an ordinary scalar or array, then give that
object CODIMENSION in this statement. It need not already have the
attribute; specifying it again can instead violate C815. The within-type-
declaration override in8.2p2 is not permission for arbitrary cross-statement
repetition.
