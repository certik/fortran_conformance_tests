### R602: Underscore has the underscore terminal

**Source:** 6.1.4 R602 (J3/24-007 PDF page 67, printed page 53, line 25). **Class:** Syntax.

**Definition:** The underscore syntax class is the single underscore character. Its use as an
alphanumeric-character comes from R601; the permitted positions in a name come from
R603. R602 does not define a kind suffix, allow an initial underscore in a name, or
prescribe a processor character code.

**Diagnostic obligation:** required.

**Facets:** `underscore-terminal`.

**Oracle:** A short name containing the underscore terminal and the corresponding name without it
denote two separately assigned integer objects. Check both values so silently discarding
the underscore cannot satisfy this admission control.

**Oracle limitation:** This is a positive control, not independent rejection coverage for invalid names or
literal-kind syntax. Those grammars retain their existing owners. A substituted special
character would also violate the enclosing grammar and is not used as a second R602
negative. Graphic appearance is separately pending under S6.1.1-001. Required diagnostic
capability under 4.2 p2(3) does not mandate fatal rejection or a particular diagnostic
code.

**Dependencies:** 4.1.1 p1 treats the terminal literally (PDF page 44); 4.2 p2(3) establishes syntax
diagnostic capability (PDF page 46). 6.1.1/R601 and 6.2.2/R603/C601 provide the legal
short-name context (PDF pages 67-68).
