### S11.1.11.1-001: SELECT TYPE selects at most one block by dynamic type and associates a name with the selector

**Source:** 11.1.11.1 p1; J3/24-007 PDF p224. **Class:** Effect.

**Definition:** A SELECT TYPE construct selects at most one constituent block for execution based on the
dynamic type of an expression. A name is associated with the expression or variable in
the same way as for ASSOCIATE. Detailed matching and associating-entity attributes are
owned by 11.1.11.2 and 11.1.3.3.

**Diagnostic obligation:** not-required.

**Facets:** `dynamic-type-selection-purpose`, `selector-associate-name-source`.

**Oracle:** This paragraph states purpose and association terminology; block selection evidence
belongs to 11.1.11.2.

**Oracle limitation:** This source-only catalogue records pending plans only. It creates no Fortran test
program, invokes no processor, approves no fixture or oracle, and claims no coverage.
Future SELECT TYPE fixtures must make declared and dynamic types genuinely
distinguishable, preload targets with sentinels distinct from every block write, and
observe only which block executed or which scoped associating-entity operations are
admitted. They must not infer type guard evaluation order, source-text search order,
selector reevaluation, temporary representation, addresses, or dynamic type from
SAME_TYPE_AS, EXTENDS_TYPE_OF, compiler agreement, message wording, or any intrinsic
that duplicates the feature under test.

**Dependencies:** 11.1.11.2 in this packet;11.1.3.3 already owns general associate-name attributes;19.4
and 19.5.1.6 NOT YET REGISTERED.
