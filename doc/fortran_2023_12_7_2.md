## WAIT/position/FLUSH fixture derivations

### `wait_id_zero_no_pending` / `S12.7.2-002`

**Facets:** `wait-id-zero-or-pending-identifier`.

12.7.2 p3 permits ID=0; on an asynchronous connection with no pending operation, WAIT with ID=0 succeeds with IOSTAT zero and no ERR/END branch.

Feature mutations: `remove-wait-id-zero`.

### `wait_no_id_unavailable` / `S12.7.2-004`

**Facets:** `wait-no-id-unconnected-unit-permitted`, `wait-no-id-nonasynchronous-unit-permitted`.

12.7.2 p4 permits WAIT without ID for unconnected and non-asynchronous units; both cases report IOSTAT zero with no timing or buffering assertion.

Feature mutations: `remove-wait-closed-unit`, `remove-wait-nonasync-unit`.

### `wait_unavailable_no_error_end` / `S12.7.2-005`

**Facets:** `wait-no-id-unavailable-unit-no-error`, `wait-no-id-unavailable-unit-no-end`.

12.7.2 p4 says permitted no-ID WAIT on an unavailable unit causes no error or EOF; IOSTAT is zero and neither ERR nor END branch is taken.

Feature mutations: `remove-unavailable-wait`, `force-error-branch-mutant`.
