### S12.5.4-001: External-unit connection is a symmetric unit-file property

**Source:** S12.5.4, J3/24-007, 18 December 2023, physical PDF250. **Class:** Effect.

external file. Connection is symmetric: the unit is connected to a file if and only if
the file is connected to the unit.
