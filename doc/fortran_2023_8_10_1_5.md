## Unit equations, not physical layout guesses

P1 forbids forcing the same storage unit into different positions of
one sequence. Sharing units across different sequences is not itself
the violation. P2 forbids associations inconsistent with consecutive
storage-unit relationships. The source plans use ordinary INTEGER
objects, valid constant bounds and finite alignment equations.

Each inconsistent input has a minimal conforming repair: change one
alignment endpoint or one existing peer occurrence. Consistent transitive
relationships, different sequence extents and forward shifted overlap
are not automatically errors. No invalid association is executed to
obtain a value oracle.

Some offset contradictions violate both paragraphs when expanded under
19.5.3.3. A gapped or reversed alignment must not be advertised as a
uniquely isolated p2 diagnostic if it also repeats a unit. That shared
cause and any evidence ownership require later adjudication, not
duplicate programs or a fictional canonical link.
