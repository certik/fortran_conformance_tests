### S11.1.7.4.1-001: DO statement execution activates a counted DO construct and establishes counted-loop parameters

**Source:** 11.1.7.4.1 p1; J3/24-007 PDF p212. **Class:** Effect.

**Definition:** When a counted DO statement is executed, the DO construct becomes active; the initial,
terminal, and incrementation parameters are established by evaluating the scalar integer
expressions with conversion to the DO-variable kind as needed; an absent increment has
value one; the increment value shall not be zero; the DO variable becomes defined with
the initial parameter; and the iteration count is established as (m2 - m1 + m3) / m3
unless that value is negative, in which case it is zero.

**Diagnostic obligation:** context-dependent.

### S11.1.7.4.1-002: Omitted loop control and WHILE loop control are initiated as an indefinite loop with a leading EXIT test

**Source:** 11.1.7.4.1 p2; J3/24-007 PDF p212. **Class:** Effect.

**Definition:** If loop-control is omitted, no iteration count is calculated and the effect is as if a
large positive iteration count impossible to decrement to zero were established. If
loop-control is WHILE (scalar-logical-expr), the effect is as if loop-control were
omitted and an IF (.NOT. scalar-logical-expr) EXIT statement were inserted as the first
statement of the block.
