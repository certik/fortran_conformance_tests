## WAIT/position/FLUSH fixture derivations

### `backspace_current_record` / `S12.8.2-001`

**Facets:** `backspace-before-current-record`.

12.8.2 p1 says BACKSPACE before a current record positions before that current record; after a nonadvancing partial read, BACKSPACE makes a full read return the same record.

Feature mutations: `remove-backspace-current`, `backspace-current-record-text`.

### `backspace_preceding_and_initial` / `S12.8.2-001`

**Facets:** `backspace-before-preceding-record`, `backspace-at-initial-point-unchanged`.

12.8.2 p1 leaves the initial point unchanged by BACKSPACE and otherwise positions before the preceding record when no current record exists; exact read-back distinguishes A from B.

Feature mutations: `remove-initial-backspace`, `remove-preceding-backspace`, `second-record-changed`.

### `backspace_implicit_endfile` / `S12.8.2-002`

**Facets:** `backspace-implicit-endfile-before-preceding-record`.

12.8.2 p2 fixes the result when BACKSPACE implicitly writes an endfile record; after output records A and B, BACKSPACE positions before B, not before an end marker.

Feature mutations: `remove-implicit-backspace`, `implicit-record-changed`.
