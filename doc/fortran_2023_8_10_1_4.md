## Nonzero size is a premise

A whole array name in an equivalence set acts like the first element
designator only when the array is nonempty. Actual lower bounds and
Table9.1 determine that element. It is not necessarily the element with
index1 in each dimension. The array does not become scalar or lose
its extent.
