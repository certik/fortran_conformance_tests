### S11.1.4-001: BLOCK is an executable construct that can contain declarations

**Source:** 11.1.4 p1; J3/24-007 PDF p205. **Class:** Effect.

**Definition:** The BLOCK construct is classified as an executable construct and can contain
declarations. The allowed specification part forms, exclusions, scope, and execution

### S11.1.4-002: BLOCK specifications declare BLOCK-scope construct entities except scoped ASYNCHRONOUS, IMPORT, and VOLATILE cases

**Source:** 11.1.4 p2; J3/24-007 PDF p206. **Class:** Effect.

**Definition:** Except for ASYNCHRONOUS, IMPORT, and VOLATILE statements, specifications in a BLOCK
construct declare construct entities whose scope is that of the BLOCK construct. If an
object name that is not a construct entity appears in ASYNCHRONOUS or VOLATILE in a
BLOCK construct, the object has that attribute within the construct even if it does not
outside.
