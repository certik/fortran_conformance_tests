### S11.1.9.1-001: SELECT CASE selects at most one block based on an expression value

**Source:** 11.1.9.1 p1; J3/24-007 PDF p219. **Class:** Effect.

**Definition:** A SELECT CASE construct selects at most one constituent block for execution, based on
the value of an expression. Detailed matching is 11.1.9.2.

**Diagnostic obligation:** not-required.

**Facets:** `at-most-one-case-block-selected`, `case-expression-value-controls-selection`.

**Oracle:** Observe selected block sentinels, not selector evaluation.

**Oracle limitation:** This source-only catalogue records pending plans only. It creates no Fortran test
program, invokes no processor, approves no fixture or oracle, and claims no coverage.
Future selection fixtures must preload targets with sentinels distinct from every block
write and observe only final values to prove which block executed. They must not infer
condition, selector, or case-value evaluation from side effects, call counts,
short-circuiting, deliberate errors, temporaries, or evaluation order. Character CASE
plans must control blank padding with equal lengths or explicit LEN checks. No plan may
assume a particular real or complex kind, use an intrinsic that duplicates the feature
under test, rely on compiler agreement, or require permission text to be exercised.

**Dependencies:** 10.1 expressions registered;11.1.1 blocks registered;11.1.9.2 in this packet.
