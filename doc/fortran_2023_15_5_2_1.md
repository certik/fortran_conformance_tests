### S15.5.2.1-001: Actual arguments correspond to dummy arguments by keyword or reduced-list position

**Source:** S15.5.2.1, J3/24-007, 18 December 2023, physical PDF337. **Class:** Effect.

**Definition:** A procedure reference actual argument list establishes actual-to-dummy correspondence by
argument keyword or by position in the reduced dummy argument list. The reduced list
omits a passed-object dummy argument. One actual argument corresponds to each
nonoptional dummy argument, at most one actual corresponds to each optional dummy
argument, and every actual corresponds to a dummy argument.
