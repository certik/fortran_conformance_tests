### S12.6.2.16-001: SIZE defines the count of characters transferred by input data edit descriptors

**Source:** S12.6.2.16, J3/24-007, 18 December 2023, physical PDF262. **Class:** Effect.

**Definition:** In an input statement, SIZE= causes the specified variable to become defined with the
count of characters transferred from the file by data edit descriptors; blanks inserted
as padding are not counted.

### S12.6.2.16-002: SIZE definition timing depends on synchronous versus asynchronous input
