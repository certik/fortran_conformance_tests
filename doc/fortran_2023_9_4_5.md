### S9.4.5-001: Type parameter inquiries interrogate data-object type parameters for intrinsic and derived types

**Source:** 9.4.5 p1, J3/24-007, 18 December 2023, physical PDF153. **Class:** Effect.

**Definition:** A type parameter inquiry is used to inquire about a type parameter of a data object. It
applies to both intrinsic and derived types. The inquired entity is a type parameter:
intrinsic type parameters are defined by the intrinsic type clauses, and derived type
parameters are integer kind or length parameters from 7.5.3.1; this subclause does not
create a non-integer data component or a structure component.

**Diagnostic obligation:** not-required.

### C923: The queried name is a type parameter of the declared type of the designated object

### S9.4.5-002: Deferred type parameters of unassociated pointers or unallocated allocatables are not inquired about

**Source:** 9.4.5 p2, J3/24-007, 18 December 2023, physical PDF153. **Class:** Restriction.

**Definition:** A deferred type parameter of a pointer that is not associated, or of an allocatable
variable that is unallocated, shall not be inquired about. The restriction is about
deferred type parameters and the pointer association or allocatable allocation status at
the inquiry; it does not prohibit inquiries of nondeferred parameters merely because the
object is a pointer or allocatable.
