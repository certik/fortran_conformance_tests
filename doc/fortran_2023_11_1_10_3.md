### S11.1.10.3-002: SELECT RANK case kind determines associating-entity rank, assumed-size status, and bounds

**Source:** 11.1.10.3 p2; J3/24-007 PDF p223. **Class:** Effect.

**Definition:** Within a RANK DEFAULT block the associating entity is assumed-rank and has exactly the
same attributes as the selector. Within a RANK(*) block it has rank 1 and is
assumed-size as if declared DIMENSION(1:*). Within a RANK(n) block it has the specified
rank, with each lower bound equal to LBOUND of the corresponding selector dimension and
each upper bound equal to UBOUND of the corresponding selector dimension.
