### S10.2.3.1-001: Masked array assignment is a WHERE statement or WHERE construct controlled by a logical array expression

**Source:** 10.2.3.1 p1; J3/24-007 PDF p197. **Class:** Effect.

**Definition:** A masked array assignment is classified as either a WHERE statement or a WHERE
construct. Its local purpose is to mask expression evaluation and value assignment in
array assignment statements according to a logical array expression; the detailed
execution of those masks is owned by 10.2.3.2.

**Diagnostic obligation:** not-required.

**Facets:** `where-statement-form-control`, `where-construct-form-control`, `logical-array-mask-control`.

**Oracle:** This requirement is classification and source-control evidence only. It does not by
itself define which elements are assigned, how expressions are evaluated, or any
diagnostic for non-WHERE syntax.

**Oracle limitation:** This source-only catalogue records pending plans only. It creates no Fortran test
program, invokes no processor, approves no fixture or oracle, and claims no coverage.
Future fixtures must use independently derived literal, inquiry, or source-relation
oracles; must inspect final element values directly for masking behavior; must not use
MERGE, PACK, COUNT, or an equivalent masking intrinsic as the oracle; must not infer
