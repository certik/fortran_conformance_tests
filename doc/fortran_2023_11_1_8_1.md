### S11.1.8.1-001: IF constructs select at most one block using a sequence of logical expressions

**Source:** 11.1.8.1 p1; J3/24-007 PDF p218. **Class:** Effect.

**Definition:** An IF construct is a selection construct in which at most one constituent block is
selected for execution, and the selection is based on a sequence of logical expressions.
Detailed execution ordering is owned by 11.1.8.2.

**Diagnostic obligation:** not-required.

**Facets:** `at-most-one-block-selected`, `logical-expression-sequence-controls-selection`.

**Oracle:** Observe block selection, not condition-evaluation side effects.

**Oracle limitation:** This source-only catalogue records pending plans only. It creates no Fortran test
program, invokes no processor, approves no fixture or oracle, and claims no coverage.

### R1136: IF construct syntax contains IF THEN, blocks, optional ELSE IF repetitions, optional ELSE, and END IF

**Source:** 11.1.8.1 R1136; J3/24-007 PDF p218. **Class:** Syntax.

**Definition:** An if-construct has an if-then-stmt and block, zero or more else-if-stmt/block pairs, an
optional else-stmt/block pair, and an end-if-stmt.

### C1147: IF construct names on IF THEN, ELSE IF or ELSE, and END IF shall correspond

**Source:** 11.1.8.1 C1147; J3/24-007 PDF p218. **Class:** Restriction.

**Definition:** If an if-then-stmt specifies an if-construct-name, the corresponding END IF shall
specify the same name; if it does not, the corresponding END IF shall not specify a
name; any ELSE IF or ELSE name shall be the same as the corresponding IF THEN name.

**Diagnostic obligation:** required.

**Facets:** `named-end-if-mismatch-rejected`, `unnamed-if-named-end-rejected`, `else-if-name-mismatch-rejected`, `else-name-mismatch-rejected`.
