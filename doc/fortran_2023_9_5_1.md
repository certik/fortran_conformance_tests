### S9.5.1-001: An array designator does not by itself prescribe element reference order

**Source:** 9.5.1 p1, J3/24-007, 18 December 2023, physical PDF154. **Class:** Effect.

**Definition:** The appearance of an array designator does not indicate an order in which the elements
of the array are referenced, except in contexts where array element ordering is
specified by 9.5.3.3. This requirement records only the absence of an ordering
implication and the explicit dependency on the array-element-order rules; it does not
define subscript order values itself.
