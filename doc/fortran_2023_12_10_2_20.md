### S12.10.2.20-001: OPENED= reports file or unit connection status

**Source:** S12.10.2.20, J3/24-007, 18 December 2023, physical PDF282. **Class:** Effect.

**Definition:** OPENED= is assigned true by file if the file is connected to a unit and false otherwise;
by unit it is assigned true if the unit is connected to a file and false otherwise.
