### S19.1-002: Identifier scope depends on identifier class and excludes shadowed nested scopes

**Source:** S19.1, J3/24-007, 18 December 2023, physical PDF548. **Class:** Effect.

**Definition:** A global identifier has program scope, a local identifier has inclusive scope, a
construct-entity identifier has construct scope, and a statement-entity identifier has
statement or part-statement scope, excluding nested scopes that treat the identifier as
another entity or make it inaccessible by IMPORT.

**Diagnostic obligation:** not-required.

**Facets:** `global-identifier-program-scope`, `local-identifier-inclusive-scope`, `construct-identifier-construct-scope`, `statement-identifier-statement-scope`, `nested-scope-shadowing-exclusion`, `import-inaccessibility-exclusion`.

**Oracle:** S19.1-002 scope runtime fixtures: two complete run/effect/f2023 programs observe local
scope boundaries with nondefault sentinels. The host/rename fixture initializes host
token=41, has one internal procedure read that same spelling by host association, and
has a second internal procedure declare a local token=73; it checks host_seen=41,
inner_seen=73, and the host token still 41. The construct fixture initializes outer
i=99, uses ASSOCIATE (i=>construct_source) to write [10,20,30], and uses an
array-constructor implied-DO [(i,i=1,3)]; it checks both produced arrays and that outer
