### S5.5.2-001: Statement keywords do not reserve same-spelled names

**Source:** 5.5.2 p1.not-reserved-name-admission, J3/24-007, 18 December 2023, physical PDF65. **Class:** Effect.

**Definition:** A name with the same spelling as a statement keyword is allowed in a context where the
grammar expects a name. This admission does not alter token spelling, case equivalence,
implicit typing, declaration ordering or the statement syntax that uses the keyword
literally.

**Diagnostic obligation:** not-required.

**Facets:** `same-spelling-name-admission`, `statement-keyword-token-separation`.

**Oracle:** The plan observes exact integer values of same-spelled names after declaration,
assignment and use. Statement execution itself is checked only through owners of the
corresponding statement syntax.

**Oracle limitation:** This is not a claim that keywords can appear in arbitrary name positions, that malformed
tokens are accepted, or that IMPLICIT NONE changes keyword status. Parser recovery text
and case-specific diagnostics are not asserted.

**Dependencies:** 6.2.2 owns name spelling and length; 6.3.2 owns token separation; 8.7 owns IMPLICIT
NONE; individual statement forms own their literal keyword syntax and execution effects.
