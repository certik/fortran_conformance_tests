### S18.4-001: A C descriptor is a CFI_cdesc_t structure for describing Fortran data objects from C

**Source:** S18.4, J3/24-007, 18 December 2023, physical PDF531. **Class:** Effect.

**Definition:** A C descriptor is a C structure of type CFI_cdesc_t, defined in ISO_Fortran_binding.h,
that together with the standard library-function prototypes provides a means for
describing and manipulating Fortran data objects from within a C function.
