### S11.1.1-001: Executable constructs containing blocks are a closed construct set

**Source:** 11.1.1 p1; J3/24-007 PDF p203. **Class:** Effect.

**Definition:** The executable constructs that contain blocks are the listed ASSOCIATE, BLOCK, CHANGE

classification of construct families; each construct owns its own syntax and execution
rules.

### R1101: A block is a possibly empty sequence of execution-part constructs

**Source:** 11.1.1 R1101; J3/24-007 PDF p203. **Class:** Syntax.

**Definition:** The grammar production for block is zero or more execution-part-constructs. Empty-block
admission and the contents of execution-part-construct are owned by the construct using
the block and by the execution-part grammar.

### S11.1.1-002: Executable constructs control block execution and bound their blocks by construct-specific statements

**Source:** 11.1.1 p2; J3/24-007 PDF p203. **Class:** Effect.

**Definition:** Executable constructs are the language mechanism for controlling which blocks execute or
how many times a block executes. Blocks are bounded by statements particular to the
