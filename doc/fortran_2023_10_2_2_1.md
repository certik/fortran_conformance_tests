### S10.2.2.1-001: Pointer assignment changes pointer association status and breaks any previous association

**Source:** 10.2.2.1 p1; J3/24-007 PDF p193. **Class:** Effect.

**Definition:** Pointer assignment is the operation that causes a pointer to become associated with a
target, disassociated, or to have undefined pointer association status; any previous
association between the pointer and a target is broken.

**Diagnostic obligation:** not-required.

**Facets:** `data-pointer-associated-status`, `procedure-pointer-associated-status`, `disassociated-status`, `undefined-status-source-boundary`, `previous-association-broken`.

**Oracle:** ASSOCIATED may be used only after the cited source establishes defined association
status; the expected result must come from the association-status rules, not from
compiler convention. Undefined status is recorded as an unobservable source state, not
as a runtime oracle.

### S10.2.2.1-002: Derived-type intrinsic assignment can perform pointer assignment for pointer components

**Source:** 10.2.2.1 p2; J3/24-007 PDF p193. **Class:** Effect.

**Definition:** Execution of a derived-type intrinsic assignment statement can also perform pointer
assignment for a pointer component of a structure; the pointer object is the pointer
component of the variable, and the target is the corresponding component of the
expression as further described by 10.2.2.2 p2.

**Diagnostic obligation:** not-required.
