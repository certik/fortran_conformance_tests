### S18.3.2-001: C_PTR and C_FUNPTR are private derived types interoperable with C pointer types

**Source:** S18.3.2, J3/24-007, 18 December 2023, physical PDF526. **Class:** Effect.

**Definition:** C_PTR and C_FUNPTR are derived types with only private direct components, no direct
allocatable or pointer components, with C_PTR interoperable with any C object pointer
type and C_FUNPTR interoperable with any C function pointer type.
