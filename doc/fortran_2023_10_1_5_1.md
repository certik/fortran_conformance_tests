### S10.1.5.1-001: Unary intrinsic operations use a unary intrinsic operator and a Table 10.2 numeric operand type

**Source:** 10.1.5.1 p1 and Table 10.2; J3/24-007 PDF p175. **Class:** Effect.

**Definition:** An intrinsic operation is unary or binary. A unary intrinsic operation has the form
intrinsic-operator x2, and Table 10.2 lists unary plus and minus for integer, real, and
complex operands with the same type category as the result.

**Facets:** `unary-plus-integer`, `unary-minus-real`, `unary-minus-complex`, `unary-logical-not-separated`.

### S10.1.5.1-003: Numeric intrinsic operations are operations with numeric operators

**Source:** 10.1.5.1 p3 and Table 10.2 numeric rows; J3/24-007 PDF p175. **Class:** Effect.

### S10.1.5.1-005: Logical intrinsic operations use logical operands and logical operators

### S10.1.5.1-006: Relational intrinsic operations cover numeric, character, enumeration, and enum operand families

**Source:** 10.1.5.1 p6 and Table 10.2; J3/24-007 PDF p175. **Class:** Restriction.

**Definition:** The relational intrinsic operators are .EQ., .NE., .GT., .GE., .LT., .LE., ==, /=, >,
>=, <, and <=. A relational intrinsic operation uses one of those operators. Numeric
relational operations have numeric operands; character relational operations have
character operands whose kind type parameters shall be the same; enumeration relational
operations have operands of the same enumeration type; enum relational operations have
one enum operand and the other operand of the same enum type or an integer expression
involving an enumerator of that type. Table 10.2 gives logical results and the admitted
equality and ordering families.
