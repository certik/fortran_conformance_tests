### S18.3.4-001: BIND(C) derived types interoperate with matching C structure types by component order

**Source:** S18.3.4, J3/24-007, 18 December 2023, physical PDF526 and PDF527. **Class:** Effect.

**Definition:** Interoperability between a Fortran derived type and a C structure type is provided by
the BIND attribute; a derived type is interoperable with a C structure type exactly with
BIND(C), the same number of components, interoperable corresponding component variables,
and correspondence by the same relative component position.

**Diagnostic obligation:** not-required.

**Facets:** `bind-attribute-provides-struct-interoperability`, `same-component-count-required`, `component-variable-interoperability-required`, `relative-position-determines-correspondence`.
