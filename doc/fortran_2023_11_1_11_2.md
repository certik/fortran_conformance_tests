### S11.1.11.2-001: SELECT TYPE evaluates selector expressions as specified before selection

**Source:** 11.1.11.2 p1; J3/24-007 PDF p225. **Class:** Effect.

**Definition:** Executing SELECT TYPE evaluates every expression within a selector that is a variable
designator, or evaluates a selector that is not a variable designator.

### S11.1.11.2-003: TYPE IS and CLASS IS guards match by dynamic type, type extension, and kind type parameter values

### S11.1.11.2-004: SELECT TYPE selects TYPE IS first, otherwise the unique or most-specific CLASS IS, otherwise CLASS DEFAULT, otherwise no block

**Source:** 11.1.11.2 p4; J3/24-007 PDF p225-p226. **Class:** Effect.
