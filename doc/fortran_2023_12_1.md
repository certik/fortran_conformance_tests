### S12.1-001: Input and output statements define reading, writing, and optional editing

**Source:** S12.1, J3/24-007, 18 December 2023, physical PDF242. **Class:** Effect.

**Definition:** Input statements transfer data from external media or internal files to internal storage
and are called reading; output statements transfer data from internal storage to
external media or internal files and are called writing; some input/output statements
specify editing.

**Diagnostic obligation:** not-required.

**Facets:** `input-reading-transfer`, `output-writing-transfer`, `editing-specified-by-some-io-statements`.
