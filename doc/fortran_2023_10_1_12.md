### S10.1.12-001: Constant-expression inquiries of same specification-part entities use prior specifications

**Source:** 10.1.12 p2; J3/24-007 PDF p188. **Class:** Restriction.

**Definition:** If a constant expression includes a specification inquiry depending on a type parameter
or array bound of an entity specified in the same specification-part, the type parameter
or array bound is specified in a prior specification of that specification-part. The
prior specification may be to the left in the same statement, but not within the same
entity-decl unless the inquiry appears within an initialization.
