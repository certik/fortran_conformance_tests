### S9.5.3.3-001: Array elements form array element order by subscript order value

**Source:** 9.5.3.3 p1, J3/24-007, 18 December 2023, physical PDF156. **Class:** Effect.

**Definition:** The elements of an array form a sequence named the array element order. The position of
an array element in that sequence is determined by the subscript order value of the
subscript list designating the element, and that value is computed from Table 9.1 rather
than from storage addresses or processor traversal order.

### S9.5.3.3-002: Table 9.1 defines subscript order value formulas through rank 15
