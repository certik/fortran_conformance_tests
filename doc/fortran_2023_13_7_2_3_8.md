## Executable input/output rounding mode fixtures

This packet adds executable fixtures for 12 selected 13.7.2.3.8 facets: OPEN, data-transfer, and edit-descriptor mode sources; decimal/internal conversion direction; and the UP, DOWN, ZERO, NEAREST non-halfway, and COMPATIBLE required rounding modes. It deliberately leaves NEAREST tie latitude, PROCESSOR_DEFINED latitude, and conditional IEEE conversion tie-even pending. The fixtures use SS for positive numeric output, avoid optional leading-zero oracles, initialize character buffers with '#', guard-check the one input target sentinel before READ, and include permanent mode/descriptor, input, oracle, and sentinel mutation probes.

### S13.7.2.3.8-002: Decimal value and internal value distinguish exact decimal text from stored approximation

**Source:** S13.7.2.3.8, J3/24-007, 18 December 2023, physical PDF301. **Class:** Effect.

**Definition:** A decimal value is the exact decimal number represented by a character string, while an
internal value is the number actually stored; formatted output converts internal to
decimal value and input converts decimal to internal value.
