### S13.7.2.3.8-002: Decimal value and internal value distinguish exact decimal text from stored approximation

**Source:** S13.7.2.3.8, J3/24-007, 18 December 2023, physical PDF301. **Class:** Effect.

internal value is the number actually stored; formatted output converts internal to
decimal value and input converts decimal to internal value.
