### S15.4.3.4.2-001: OPERATOR generic specifications require suitable function specifics

**Source:** 15.4.3.4.2, J3/24-007, 18 December 2023, physical PDF329. **Class:** Restriction.

**Definition:** An OPERATOR generic specification names only functions usable as defined operations;
arity is one or two, dummy arguments are nonoptional dummy data objects with INTENT(IN)
or VALUE, the result is not assumed character length, and intrinsic-operator extensions
have arity consistent with intrinsic use while differing from intrinsic operations by
type, kind, or rank, with CLASS(*) not counted as type/kind difference.

### S15.4.3.4.2-002: Defined operation notation follows unary prefix and binary infix function references

**Source:** 15.4.3.4.2, J3/24-007, 18 December 2023, physical PDF329. **Class:** Effect.

**Definition:** A defined operation is treated as a function reference: unary notation passes the
operand as the dummy argument, binary infix notation passes the left operand to the
first dummy and the right operand to the second, and actual-argument restrictions for
