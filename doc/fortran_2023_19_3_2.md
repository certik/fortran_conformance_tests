### S19.3.2-002: A local identifier that matches a common block name denotes the local entity outside common-block-name contexts

**Source:** S19.3.2, J3/24-007, 18 December 2023, physical PDF550. **Class:** Effect.

**Definition:** For a local identifier of class (1) that is also the name of a common block, any
appearance of that name outside BIND, COMMON, or SAVE common-block-name contexts is an
appearance of the local identifier.

**Diagnostic obligation:** not-required.

**Facets:** `common-block-homonym-local-reference`.

**Oracle:** S19.3.2-002 common-block homonym runtime fixture: one complete program declares COMMON
/blk/ cb_member and a local integer blk. It initializes cb_member=29 and blk=17,
evaluates ordinary expression blk+1 expecting 18, and checks cb_member remains 29,
proving ordinary occurrences resolve to the local identifier rather than the common
block.
