### S18.3.3-001: Fortran enum types interoperate with corresponding C enumerated and integer types

**Source:** S18.3.3, J3/24-007, 18 December 2023, physical PDF526. **Class:** Effect.

**Definition:** An enum type interoperates with its corresponding C enumerated type and with the C
integer type that interoperates with its enumerators.
