### S19.5.1.5-001: BIND module variables and Fortran common blocks have program-long C linkage association

**Source:** S19.5.1.5, J3/24-007, 18 December 2023, physical PDF555. **Class:** Effect.

**Definition:** Linkage association occurs between a BIND module variable and the interoperating C
variable, or between a Fortran common block and the interoperating C variable, and
remains in effect throughout program execution.

**Diagnostic obligation:** not-required.

**Facets:** `bind-module-variable-c-linkage`, `common-block-c-linkage`, `linkage-association-program-long`.

**Oracle:** S19.5.1.5-001 BIND(C) linkage runtime fixture: a Fortran module variable with
BIND(C,name='assoc_link_value') is modified by C companion functions to 42 and then 77,
and Fortran reads both exact values through the same variable, proving C linkage and
program-long persistence. COMMON/C linkage remains pending because the suite supports C
sources but this packet ships only the portable BIND module-variable companion.
