### S15.9.3-001: Elemental subroutine references with array OUT or INOUT actuals produce elementwise result values

**Source:** 15.9.3 p1; J3/24-007, 18 December 2023 PDF p363. **Class:** Effect.

**Definition:** In an elemental subroutine reference, array actual arguments corresponding to
INTENT(OUT) and INTENT(INOUT) dummy arguments receive element values as would be
obtained by applying the subroutine separately in array element order to corresponding
elements of each array actual argument.

**Diagnostic obligation:** not-required.

**Facets:** `elemental-subroutine-array-out-values`, `elemental-subroutine-array-inout-values`, `elemental-subroutine-array-element-order-values`, `elemental-subroutine-empty-array-results`.

**Oracle:** The OUT plan is hand-computed as 3*x+1: inputs 2, 5, 7, 11 give 7, 16, 22, 34. The order
plan starts counter at 100, increments before storing, and computes counter*10+x, giving
1011, 1022, 1033 in array element order.
