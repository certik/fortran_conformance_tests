### S10.1.1-001: An expression represents a data object reference or a computation

**Source:** 10.1.1 p1, first sentence; J3/24-007 PDF p168. **Class:** Effect.

**Definition:** An expression denotes either a data object reference or a computation, and the value
represented by the expression is scalar or array. This catalogue records that
representational boundary without duplicating designator, variable, operation, or result
interpretation rules.

**Diagnostic obligation:** not-required.

**Facets:** `data-object-reference-expression`, `computation-expression`, `scalar-expression-value`, `array-expression-value`.

**Oracle:** Future controls compare reached scalar or array values against independent literals
after satisfying the owning designator, operation, and assignment rules. No test may
infer expression representation from storage addresses or from a processor's chosen
evaluation order.

**Oracle limitation:** This source-only catalogue records pending plans only. It creates no Fortran test
program, invokes no processor, approves no fixture or oracle, and claims no coverage.
Numbered syntax rules and constraints carry the 4.2 diagnostic-capability duty, but
future negative plans must isolate the cited rule or constraint and must not rely on
compiler agreement, address arithmetic, TRANSFER, emitted code, undefined reads, or

### S10.1.1-002: Evaluation of an expression produces a typed value with parameters and shape

**Source:** 10.1.1 p1, second sentence; J3/24-007 PDF p168. **Class:** Effect.

**Definition:** When an expression is evaluated it produces a value, and that value has a type, has type
parameters when appropriate, and has a shape. The detailed determination of those
properties is delegated to the later expression-result subclauses.

**Diagnostic obligation:** not-required.

**Facets:** `integer-type-value`, `character-length-parameter`, `derived-type-parameter`, `scalar-shape`, `array-shape`.

### S10.1.1-003: A non-variable expression has corank zero

**Source:** 10.1.1 p1, third sentence; J3/24-007 PDF p168. **Class:** Effect.

**Definition:** The corank of an expression that is not a variable is zero. This does not redefine which
expressions are variables, nor the separate rules for coarray variables and coindexed
designators.

**Diagnostic obligation:** not-required.

**Facets:** `literal-nonvariable-corank-zero`, `computed-nonvariable-corank-zero`, `parenthesized-variable-boundary`.

**Oracle:** Future observations need an independently owned corank-sensitive context and a literal
value check to prove execution. A coarray declaration alone is not evidence that a
non-variable expression has nonzero corank.
