### S10.1.5.4.1-001: Logical intrinsic operations express logical computations and produce logical results

**Source:** 10.1.5.4.1 p1; J3/24-007 PDF p179. **Class:** Effect.

**Definition:** A logical intrinsic operation expresses a logical computation and, when evaluated,
produces a result of type logical. The permitted operand types are not redefined here;
they are the logical operand rules specified in 10.1.5.1.

**Diagnostic obligation:** not-required.

**Facets:** `logical-computation-context`, `logical-result-type`, `operand-type-delegation`.

**Oracle:** Use only literal logical values or standard logical inquiries. Truth-table controls must
not contain operand side effects, function-call counters, undefined branches, or any
assertion that .AND. or .OR. skipped an operand; Fortran does not require short-circuit
evaluation. Grouping of an associative intrinsic logical operation is not
value-observable, so any future grouping witness must be a valid non-associative defined
extension attributed to 10.1.6 and 15.4.3.4.2.

### S10.1.5.4.1-002: .NOT. is logical negation

**Source:** 10.1.5.4.1 Table 10.5 .NOT. row and Table 10.6 .NOT. column; J3/24-007 PDF p179. **Class:** Effect.
