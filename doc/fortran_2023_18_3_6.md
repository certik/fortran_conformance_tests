### S18.3.6-001: Named Fortran arrays are interoperable under array eligibility conditions

**Source:** S18.3.6, J3/24-007, 18 December 2023, physical PDF528. **Class:** Effect.

**Definition:** A named Fortran array is interoperable exactly with interoperable type and type
