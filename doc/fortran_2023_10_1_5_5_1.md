### S10.1.5.5.1-001: Relational intrinsic operations compare two operands and produce default logical results

**Source:** 10.1.5.5.1 p1 and p3; J3/24-007 PDF p180. **Class:** Effect.

**Definition:** A relational intrinsic operation compares the values of two operands using one of the
relational intrinsic operators and evaluation produces a default logical result. Operand
type admission is specified in 10.1.5.1, not redefined by this subclause.

**Diagnostic obligation:** not-required.

**Facets:** `listed-operator-set`, `two-operand-comparison`, `default-logical-result`, `type-admission-delegation`.

**Oracle:** Use exact small numeric, enumeration, enum, and same-kind character literals with
independent oracles; the logical aspect is the default LOGICAL result yielded by the
relational operation, not logical operands. Character relational plans must explicitly
apply the blank-padding rule before comparing and must use operand lengths that make the
intended padded comparison the actual comparison. Character ordering oracles are limited
to relationships fixed by the character-collation owner; processor-dependent collation,
nondefault blank padding, IEEE NaNs, and mathematically equivalent floating rewrites
cannot be hidden behind compiler agreement or tolerances.

### S10.1.5.5.1-010: Character relational equality compares padded same-kind character sequences

**Source:** 10.1.5.5.1 p7-p8; J3/24-007 PDF p180-181. **Class:** Effect.

**Definition:** A character relational intrinsic operation has logical value true if and only if the
operands satisfy the specified relation. The operands are compared character by
character from the first position; if lengths are unequal, the shorter operand is
treated as if extended on the right with blanks to the length of the longer. Two
zero-length operands are equal, and operands are equal if every corresponding character
is the same after padding.

### S10.1.5.5.1-011: Character relational ordering uses the first differing character and the collating sequence

**Source:** 10.1.5.5.1 p8 and NOTE 2; J3/24-007 PDF p180-181. **Class:** Effect.

**Definition:** For a character relational operation, otherwise unequal operands are ordered by the
first position where their characters differ after right blank padding. At that first
difference, x1 is less than x2 if x1's character value precedes x2's value in the
collating sequence, and greater if it follows. The collating sequence is partly
processor dependent, and for nondefault character kinds the blank padding character is
processor dependent.
