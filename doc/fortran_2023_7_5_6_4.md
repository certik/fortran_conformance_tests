### S7.5.6.4-001: Image termination does not finalize entities that already exist

**Source:** 7.5.6.4 p1; J3/24-007, 18 December 2023, physical PDF 103. **Class:** Effect.

**Definition:** On image execution termination by an error, STOP statement, ERROR STOP statement, or END
PROGRAM statement, entities existing immediately before termination are not finalized.

**Diagnostic obligation:** not-required.

**Facets:** `end-program-suppresses-existing-entity-finalization`, `stop-stmt-suppresses-existing-entity-finalization`, `error-stop-stmt-suppresses-existing-entity-finalization`, `error-termination-suppresses-existing-entity-finalization`.

**Oracle:** Each plan observes only explicitly flushed stdout markers: the route-specific BEFORE
marker must appear and the FINAL marker must not. Exit status, STOP/ERROR STOP codes,
processor banners, allocation diagnostic text, finalization order among multiple
entities, file closure timing, and multi-image behavior are not compared. Anti-vacuity
comes from a companion ordinary subroutine-return program using the same type and FINAL
subroutine; 7.5.6.3 S7.5.6.3-003 requires that companion to print the FINAL marker.
