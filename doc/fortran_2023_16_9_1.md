### S16.9.1-001: Intrinsic procedure invocations require representable assigned and returned values

**Source:** 16.9.1 p2 third sentence; J3/24-007, 18 December 2023, physical PDF376. **Class:** Restriction.

**Definition:** A program shall not invoke an intrinsic procedure when a value to be assigned to a
subroutine argument or returned as a function result is not representable by objects of
the specified type and type parameters.

**Diagnostic obligation:** not-required.

### S16.9.1-002: Deferred-length character intrinsic arguments are assigned as by intrinsic assignment

### S16.9.1-003: IEEE exception flags reflect intrinsic infinity and NaN results for finite arguments

**Source:** 16.9.1 p4; J3/24-007, 18 December 2023, physical PDF376. **Class:** Effect.

**Definition:** If finite actual arguments to an intrinsic procedure assign or return an IEEE infinity
while IEEE_ARITHMETIC is accessible, IEEE_OVERFLOW or IEEE_DIVIDE_BY_ZERO shall signal;
if they assign or return an IEEE NaN and IEEE_INVALID is supported, IEEE_INVALID shall
signal; if no IEEE infinity or NaN is assigned or returned, these flags shall retain
their invocation status.

**Diagnostic obligation:** not-required.

**Facets:** `ieee-infinity-result-signals-overflow-or-divide-by-zero`, `ieee-nan-result-signals-invalid-when-supported`, `ieee-flags-unchanged-without-infinity-or-nan`.
