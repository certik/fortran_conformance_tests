### C1175: Each computed GO TO label designates a branch target in the same inclusive scope

**Source:** 11.2.3 C1175; J3/24-007 PDF p228. **Class:** Restriction.

**Definition:** Each label in the label-list of a computed GO TO statement shall be the statement label
of a branch target statement that appears in the same inclusive scope as the
computed-goto-stmt.

**Diagnostic obligation:** required.

**Facets:** `computed-go-to-valid-labels-control`, `computed-go-to-nonbranch-target-label-rejected`, `computed-go-to-out-of-scope-label-rejected`.

### S11.2.3-001: Executing computed GO TO selects an in-range label or continues for out-of-range values

**Source:** 11.2.3 p1; J3/24-007 PDF p228. **Class:** Effect.

**Definition:** Execution of a computed GO TO evaluates the scalar integer expression. If its value is i
with 1 <= i <= n, where n is the number of labels in the label-list, a branch occurs to
the branch target statement identified by the i-th label. If i is less than 1 or greater
than n, execution continues as though a CONTINUE statement were executed.

**Diagnostic obligation:** not-required.

**Facets:** `selector-expression-evaluated`, `first-label-selected`, `middle-or-last-label-selected`, `low-out-of-range-continues`, `high-out-of-range-continues`.

**Oracle:** Use distinct sentinels for every label target and for fallthrough. The out-of-range
behavior is a normal execution effect, not an error or processor latitude.

**Oracle limitation:** This source-only catalogue records pending plans only. It creates no Fortran test
program, invokes no processor, approves no fixture or oracle, and claims no coverage.
Branching effects must be observed with distinguishable sentinels for the statement
reached next; tests must not inspect implementation jump mechanics or attribute a
branch-target violation to more than one rule.

**Dependencies:** C1175 in this section;11.3 CONTINUE statement in this packet;10.1.4 expression
evaluation registered.
