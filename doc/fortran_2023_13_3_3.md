### S13.3.3-001: A field is the record part processed for a data or character string edit descriptor

**Source:** S13.3.3, J3/24-007, 18 December 2023, physical PDF292. **Class:** Effect.

**Definition:** A field is the part of a record read or written when format control encounters a data
edit descriptor or character string edit descriptor; field width is its size in
characters.
