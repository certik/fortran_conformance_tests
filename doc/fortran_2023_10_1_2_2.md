### R1001: A primary is one of eleven expression atoms

**Source:** 10.1.2.2 R1001; J3/24-007 PDF pp168-169. **Class:** Syntax.

**Definition:** The syntactic class primary is exactly one of: literal-constant, designator,
array-constructor, structure-constructor, enum-constructor, enumeration-constructor,
function-reference, type-param-inquiry, type-param-name, parenthesized expr, or
conditional-expr. The alternatives' internal formation and semantics remain with their
owning subclauses.

**Facets:** `literal-constant`, `designator`, `array-constructor`, `structure-constructor`, `enum-constructor`, `enumeration-constructor`, `function-reference`, `type-param-inquiry`, `type-param-name`, `parenthesized-expr`, `conditional-expr`, `nonprimary-token-rejected`.

**Oracle:** Future positive controls each exercise one alternative with an independent literal or
inquiry oracle. The one negative must fail before alternative-specific constraints,
proving no R1001 alternative applies.

### C1001: A type-param-name primary names a type parameter

**Source:** 10.1.2.2 C1001; J3/24-007 PDF p168. **Class:** Restriction.

**Definition:** When the R1001 type-param-name alternative is used, the name shall be the name of a type
parameter. An ordinary object, component, procedure, or undeclared name does not satisfy

### C1002: A primary designator is not a whole assumed-size array

**Source:** 10.1.2.2 C1002; J3/24-007 PDF p168. **Class:** Restriction.

**Definition:** When the R1001 designator alternative is used as a primary, that designator shall not be

### C1003: A parenthesized expr primary is not a procedure-pointer-valued function reference

**Source:** 10.1.2.2 C1003; J3/24-007 PDF p168. **Class:** Restriction.

**Definition:** For the R1001 parenthesized expr alternative, the contained expr shall not be a function
reference that returns a procedure pointer. Other parenthesized expressions remain
admitted when their contained expression is valid.

**Facets:** `ordinary-parenthesized-expression`, `data-pointer-function-control`, `procedure-pointer-function-reference-rejected`.
