### S16.3.3-001: BOZ arguments to INT and REAL are padded or truncated to result size

**Source:** S16.3.3, J3/24-007, 18 December 2023, physical PDF366. **Class:** Effect.

**Definition:** When a boz-literal-constant is argument A of INT or REAL, shorter bit sequences are
left-padded with zeros and longer sequences are truncated from the left to the size in
bits of a scalar result of the same type and kind.
