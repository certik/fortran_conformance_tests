## OPEN specifier fixture derivations

### `position_rewind_existing` / `S12.5.6.15-004`

**Facets:** `position-rewind-initial`.

12.5.6.15 p1 says POSITION='REWIND' positions an existing file at its initial point; the first of two records is read next.

Feature mutations: `position-rewind-to-append`.

### `position_asis_connected` / `S12.5.6.15-007`

**Facets:** `position-asis-connected-unchanged`.

12.5.6.15 p1 says ASIS leaves position unchanged for an existing connected file; after one read, same-unit OPEN leaves the second record next.

Feature mutations: `position-asis-to-rewind`.

### `position_append_stream_terminal` / `S12.5.6.15-006`

**Facets:** `position-append-terminal-no-endfile`.

12.5.6.15 p1 positions an existing stream file with no endfile at its terminal point under APPEND; IOLENGTH-derived positions show A then appended B.

Feature mutations: `position-append-stream-to-rewind`.

### `position_append_before_endfile` / `S12.5.6.15-005`

**Facets:** `position-append-before-endfile`.

12.5.6.15 p1 says APPEND positions before an existing endfile record; a later write replaces that endfile so the two data records read in order.

Feature mutations: `position-append-endfile-to-rewind`.

### `position_value_append_token` / `S12.5.6.15-001`

**Facets:** `position-value-set-asis-rewind-append`.

12.5.6.15 p1 lists APPEND as a POSITION value; on an existing stream file, INQUIRE(POSITION=) observes end positioning.

Feature mutations: `position-append-token-to-rewind`.
