### S7.4.4.1-001: Character strings have ordered positions and nonnegative length

**Source:** 7.4.4.1 p1; J3/24-007, 18 December 2023, PDF 84, printed 70, lines 3-6. **Class:** Effect.

**Definition:** Character values are strings: sequences of characters with positions starting at one on
the left. Their length counts characters, not source bytes, storage units, or displayed
glyphs. LEN is a nonnegative type parameter whose integer kind is processor dependent. A
zero-length string is a value, not an invalid declaration. An expression specifying a
negative character length has the zero-length interpretation in 7.4.4.2 p5; it is not a
counterexample to nonnegative actual LEN.

**Diagnostic obligation:** not-required.

**Facets:** `ordered-positions`, `zero-and-positive-lengths`, `length-parameter-integer-kind`.

**Oracle:** Two run programs check every position in a four-character value and exact LEN/%LEN
values for lengths 0, 1 and 4, including an array. Zero-length values are never indexed.
The typed integer-kind inquiry remains a pending canonical link. Direct case IDs:
S7_4_4_1_001_valid__lengths, S7_4_4_1_001_valid__positions.

**Oracle limitation:** No negative twin is inferred from this value definition. These finite witnesses do not
enumerate a processor's value set, specify LEN's storage representation, or prove
source-byte decoding or graphics. No inquiry is made of an absent optional argument,
unallocated deferred-length object, or disassociated deferred-length pointer.

**Dependencies:** 7.2 p2-p3 and R701/C702 (PDF 76); 7.4.4.2 p4-p5 (PDF 85); 9.4.1 p1-p3/R908-R910 (PDF
151); 9.4.5/R916/C923/p2 (PDF 153); 10.1.9.2 p1 (PDF 184) makes a parameter inquiry a
scalar integer of the parameter's kind; 10.1.5.5.1 p7-p8 (PDF 180-181) supplies
same-kind equality; 16.9.118 and 16.9.122 (PDF 424, 426).

### S7.4.4.1-002: Character representation methods have kind identifiers and inquiries

**Source:** 7.4.4.1 p2, first four sentences; PDF 84, printed 70, lines 7-11. **Class:** Effect.

**Definition:** At least one character representation method is required. Each method determines a
character value set and is identified by a default-integer KIND parameter value. KIND
inquires that value; SELECTED_CHAR_KIND selects by character-type name under its own
contract. The existence requirement does not require a nondefault method or support for
either named ASCII or ISO_10646 kind. No numerical identifier, ordering of identifiers,
byte width, or equality with an integer/real kind is specified.

**Diagnostic obligation:** not-required.

**Facets:** `required-default-method`, `method-kind-inquiry`, `named-method-selection`, `representation-inventory`.

**Oracle:** Default-method declarations and DEFAULT selection are required unprofiled run controls.
A separate run checks case/trailing-blank equivalence for DEFAULT, ASCII and ISO_10646
and membership of nonnegative results in CHARACTER_KINDS, without instantiating optional
kinds. This does not establish full value sets or source mapping. Direct case IDs:
S7_4_4_1_002_valid__default_method, S7_4_4_1_002_valid__named_selection.

**Oracle limitation:** A selected kind can equal the default kind; no distinct-kind assertion is made without
an independent premise. CHARACTER_KINDS order is unspecified. Finite successful
declarations or a compiler's familiar numeric kind values do not prove complete
repertoire support. Missing method implementation is an observation failure; only
genuine optional-method absence can make its qualified witness unavailable.

**Dependencies:** 7.4.1 p2 (PDF 80) and 7.4.4.2 p2-p3/C724 (PDF 84); 9.4.5 and 10.1.9.2 p1 (PDF 153, 184);
16.9.118 (PDF 424); 16.9.180 p3-p5 (PDF 454); 16.10.2.4 (PDF 472) defines
CHARACTER_KINDS as a rank-one default-integer constant with lower bound one and
processor-dependent order. 4.2 p6-p8 (PDF 47) distinguishes processor-dependent
semantics and recommended documentation.

### S7.4.4.1-003: Representable characters can be members of strings of their method

**Source:** 7.4.4.1 p2, last sentence; PDF 84, printed 70, lines 11-12. **Class:** Effect.

**Definition:** A character that the processor can represent in a particular character method can occur
in a string of that same method. This concerns data values, including representable
control characters; it does not admit every corresponding byte in a source literal,
require additional source characters, or allow arbitrary cross-kind conversion.
Free/fixed literal admission and source-interface restrictions remain separate.

**Diagnostic obligation:** not-required.

**Facets:** `required-repertoire-in-strings`, `constructed-character-members`, `additional-repertoire-members`.

**Oracle:** CHAR(0,KIND=KIND('A')) supplies one in-domain character of the required nonempty default
method. A run checks its position and count inside a three-character string. It is not
identified as NUL, graphic or control, and no ICHAR capacity or byte layout is presumed.
Direct case IDs: S7_4_4_1_003_valid__constructed.

**Oracle limitation:** The additional-value witness needs processor evidence not yet available. It is not
permissible to infer that all integers are valid CHAR inputs, that indices fit a
narrower selected integer kind, or that every possible code is graphic. No invalid
program or mandated trap follows from the ability to hold a valid value.
