### S10.2.1.2-001: Intrinsic assignment is the assignment branch that is not defined assignment

**Source:** 10.2.1.2 p1 first sentence; J3/24-007 PDF p189. **Class:** Restriction.

**Definition:** An intrinsic assignment statement is an assignment statement that is not a defined
assignment statement. This classifying rule determines when the eligibility restrictions
of 10.2.1.2 and the interpretation rules of 10.2.1.3 apply.

**Diagnostic obligation:** context-dependent.

**Facets:** `ordinary-intrinsic-control`, `defined-assignment-exclusion`, `generic-interface-boundary`.

**Oracle:** A future case must first decide whether the statement is defined assignment. Do not
claim 10.2.1.3 effects for a top-level defined assignment, even if its implementation
subroutine performs intrinsic assignments internally.

### S10.2.1.2-002: A polymorphic intrinsic-assignment variable is allocatable and excludes coarray exposure

**Source:** 10.2.1.2 p1 item (1); J3/24-007 PDF p189. **Class:** Restriction.

### S10.2.1.2-003: Intrinsic assignment requires array/rank and conformance eligibility, with the allocatable same-rank exception

**Source:** 10.2.1.2 p1 items (2)-(3); J3/24-007 PDF p189. **Class:** Restriction.

**Definition:** If expr is an array, the variable shall also be an array. The variable and expr shall be
conformable unless the variable is an allocatable array of the same rank as expr and is

### S10.2.1.2-007: Character intrinsic assignment has kind-compatibility restrictions

**Source:** 10.2.1.2 p1 items (7)-(8); J3/24-007 PDF p189. **Class:** Restriction.
