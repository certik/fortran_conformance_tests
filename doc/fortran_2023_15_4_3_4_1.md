### S15.4.3.4.1-001: Generic interface blocks and GENERIC statements specify explicit generic interfaces

**Source:** 15.4.3.4.1, J3/24-007, 18 December 2023, physical PDF328. **Class:** Effect.

**Definition:** A generic interface block specifies a generic interface for every procedure in the
block; PROCEDURE lists nonintrinsic procedures with explicit interfaces that have the
generic interface; a GENERIC statement specifies a generic interface for each listed
specific procedure; every generic interface is explicit.
