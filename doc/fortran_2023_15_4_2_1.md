### S15.4.2.1-001: Procedure interfaces are explicit in the listed cases and implicit otherwise; statement functions are always implicit

**Source:** S15.4.2.1, J3/24-007, 18 December 2023, physical PDF325. **Class:** Effect.

**Definition:** A procedure interface is explicit for internal, module, and intrinsic procedures; for a
subroutine or separate-result-name function inside its defining scoping unit; for a
procedure declaration statement specifying an explicit interface; and for an interface
body. Otherwise the identifier interface is implicit, and a statement function interface
is always implicit.

**Diagnostic obligation:** not-required.
