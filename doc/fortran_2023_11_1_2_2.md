### S11.1.2.2-001: Block execution begins with the first executable construct in the block

**Source:** 11.1.2.2 p1; J3/24-007 PDF p203. **Class:** Effect.

**Definition:** Execution of a block begins by executing its first executable construct. Empty-block
consequences are determined by the construct that contains the block and by its own
execution rule.

**Diagnostic obligation:** not-required.

**Facets:** `first-construct-reached`, `empty-block-source-boundary`.

**Oracle:** Use final values from ordinary assignments, not call counts or side effects, to
establish the beginning of nonempty block execution.

### S11.1.2.2-002: Block execution completes through last-construct completion, outward branch, RETURN, or containing EXIT/CYCLE

**Source:** 11.1.2.2 p2; J3/24-007 PDF p203. **Class:** Effect.

**Definition:** Execution of a block is completed when the last executable construct completes without
branching to a statement in the block, when a branch within the block has a target
outside the block, when a RETURN statement in the block executes, or when an EXIT or
CYCLE statement that belongs to a construct containing the block executes.

**Diagnostic obligation:** not-required.

**Facets:** `last-construct-completion`, `outward-branch-completion`, `return-completion-source`, `exit-cycle-containing-construct-completion-source`.

**Oracle:** This requirement enumerates completion causes; it does not define branch syntax, RETURN
effects, EXIT/CYCLE ownership, or any statement execution count.
