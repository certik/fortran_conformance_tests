### S9.5.3.4.1-001: Section subscript lists contribute scalar subscripts or possibly empty subscript sequences

**Source:** 9.5.3.4.1 p1 sentence 1 and sentence 3, J3/24-007, 18 December 2023, physical PDF156. **Class:** Effect.

**Definition:** In an array section that has a section-subscript-list, each subscript triplet and
vector-subscript in that list indicates a sequence of subscripts, and the sequence may
be empty. The array section is the set of elements from the array determined by all
possible subscript lists obtainable from the single subscripts and these indicated
subscript sequences.

### S9.5.3.4.1-003: Array section rank, shape, zero size, and element order are determined by nonzero-rank parts or section-subscript sequences

**Source:** 9.5.3.4.1 p2, J3/24-007, 18 December 2023, physical PDF156-PDF157. **Class:** Effect.

**Definition:** For an array-section with no section-subscript-list, the rank and shape are those of the
nonzero-rank part-ref. Otherwise, the rank is the number of subscript triplets and
vector subscripts in the section-subscript-list, the shape is the rank-one array whose
ith element is the count of integer values in the ith such sequence, any empty sequence
makes the section size zero, and the subscript order of section elements is that of the
array data object represented.
