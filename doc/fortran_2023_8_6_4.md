### R836: A bind-entity is an entity name or a slash-delimited common-block name

**Source:** 8.6.4 R836, physical PDF135 **Class:** Syntax.

**Definition:** The two bind-entity forms are an entity-name and a common-block-name enclosed in a pair

### C877: NAME in a BIND statement requires exactly one bind-entity

**Source:** 8.6.4 C877, physical PDF135 **Class:** Restriction.

**Definition:** If the statement's language-binding-spec includes NAME=, its bind-entity list has
exactly one item. The condition is NAME presence, not a nonempty binding label: empty
and all-blank NAME values still activate it. One slash-delimited COMMON block remains
one item even when it has several members. Without NAME, this particular one-item
constraint is inactive, but the list remains nonempty and all other eligibility and
identity rules still apply.

**Diagnostic obligation:** required.

**Facets:** `two-variables-empty-name`, `two-blocks-empty-name`, `mixed-empty-name`, `blank-name-still-conditional`, `single-variable-name`, `single-block-many-members`, `without-name-list`, `nonempty-label-collision-gate`.

**Oracle:** Count the syntactic bind-entities in the actual BIND statement and test NAME presence
independently of trimming/label existence. Use empty or blank NAME two-item negatives
