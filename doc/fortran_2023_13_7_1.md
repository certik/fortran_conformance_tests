### S13.7.1-001: Data edit descriptors convert data and define/evaluate the corresponding item

**Source:** S13.7.1, J3/24-007, 18 December 2023, physical PDF294. **Class:** Effect.

**Definition:** A data edit descriptor converts data to or from internal representation; on successful
input the variable becomes defined, and on output the expression is evaluated. A or AT
editing can also position formatted stream output.

### S13.7.1-004: Unicode output transmits ISO 10646 characters and has processor-dependent unrepresentable-character results

**Source:** S13.7.1, J3/24-007, 18 December 2023, physical PDF294. **Class:** Effect.

**Definition:** During output to a Unicode file, transmitted characters are of ISO 10646 character kind;
if a character effective item or character string edit descriptor contains a character
not representable as ISO 10646, the result is processor dependent.
