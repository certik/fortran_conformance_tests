## OPEN specifier fixture derivations

### `file_names` / `S12.5.6.10-001`

**Facets:** `file-specifier-names-connected-file`.

12.5.6.10 p1 says FILE names the connected file and ignores trailing blanks; both checks create files before STATUS='OLD' and distinguish the named file by exact read-back.

Feature mutations: `main-reopen-other-existing-file`, `trailing-reopen-other-existing-file`.

### `file_trailing_blanks` / `S12.5.6.10-002`

**Facets:** `file-name-trailing-blanks-ignored`.

12.5.6.10 p1 ignores trailing blanks in FILE=; the STATUS='OLD' open uses an already-created name without blanks and reads the same exact record.

Feature mutations: `trailing-reopen-uses-other-existing`.
